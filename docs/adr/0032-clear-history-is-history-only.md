# 历史记录窗口的「清除历史记录…」只清历史记录

[ADR-0031](0031-clear-history-from-the-history-window.md) 让历史记录窗口的「清除历史记录…」直接复用设置里的「清除浏览数据」对话框，只是把默认勾选改成「历史记录」一项。按钮上写的是「清除历史记录」，对话框里却还摆着 Cookie、缓存、网页权限例外这几个勾选框，名不副实：用户顺手多勾一个，就会被各个网站登出。现在这个按钮弹出一个**专门的「清除历史记录」对话框**，外观跟「清除浏览数据」一致，但**只有一个时间范围选择器**（选项相同：过去 1 小时、24 小时、7 天、4 周、时间不限），**只清历史记录**，不碰任何网站数据。要清网站数据，仍然走「历史记录」菜单或设置里的「清除浏览数据…」。

## Considered Options

- **保留 ADR-0031 的做法**：同一个对话框只在一处定义，但按钮名和对话框能做的事对不上。
- **照 Safari 的选项改成「最近一小时 / 今天 / 今天和昨天 / 所有历史记录」**：这样历史记录窗口和「清除浏览数据」的时间范围就成了两套说法；沿用同一套，用户只需要认一种。

## Consequences

- 清除由 `HistoryBrowser.clearHistory(from:)` 完成（MochiCore，有测试），按访问时间删除，跟「清除浏览数据」里的「历史记录」一项语义相同。为了把 `SettingsController` 一路传进历史记录窗口而加的那串闭包随之删除，「清除浏览数据」对话框也回到只有设置这一处入口。
