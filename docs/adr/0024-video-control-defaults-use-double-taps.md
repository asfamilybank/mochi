# 视频控制默认键：后退、前进用连按两次

[ADR-0020](0020-video-control-listens-never-intercepts.md) 定的默认键是轻按右 ⌥ 播放/暂停、轻按右 ⌘ 后退，前进默认不绑定——剩下的修饰键都有副作用（右 ⇧ 会切换很多中文输入法），Mochi 不替用户占。[ADR-0022](0022-trigger-key-three-kinds.md) 引入连按两次时特意保持默认配置里没有连按两次，好让默认手感不变。

## 决定

默认键改为：

- 播放/暂停：轻按右 ⌥（不变）；
- 后退：连按两次右 ⌘；
- 前进：连按两次右 ⌥。

三个动作都落在右 ⌥ 和右 ⌘ 两颗键上，开箱即有前进，又不去占别的修饰键。

## 代价

右 ⌥ 默认就是两用的，所以默认的播放/暂停要等过连按间隔（约 0.3 秒）、确认不是连按两次才触发——ADR-0022 里"默认手感不变"这一条不再成立。右 ⌘ 单按默认不再绑定任何动作，后退从一下变成两下。

## Consequences

- 配置只存覆盖值，没改过这几个键的用户升级后自动用上新默认值；改过的保持原样。
- 用户想要立即响应的播放/暂停，可以把前进改绑到别的键，右 ⌥ 就不再两用。
