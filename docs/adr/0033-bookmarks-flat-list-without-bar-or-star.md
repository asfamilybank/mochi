# 书签只有一份平铺列表，没有书签栏和星标

Mochi 新增书签，但 Widget 只有一个页面、没有标签页（[ADR-0002](0002-widget-config-instance-unified.md)），所以书签在这里只做一件事：把当前页面换成另一个网站。Chrome 和 Safari 里围绕标签页长出来的那些能力，比如「在新标签页打开」「整个文件夹一次打开」，Mochi 都用不上。因此书签只有**一份平铺、可以手动排序的列表**：没有文件夹，同一个网址只能有一个书签（比较时去掉 `#` 后面的部分）。

书签只在三个地方出现：

- **「书签」菜单**：位置照 Safari，放在「历史记录」和「窗口」之间。⌘D 用来添加或编辑书签，⌥⌘B 打开书签窗口，下面平铺列出全部书签。
- **地址栏**：点进地址栏还没开始输入时，下拉列表显示全部书签，详见 [ADR-0034](0034-address-suggestions-local-only.md)。
- **书签窗口**：可以新建、编辑、拖动排序、删除和搜索书签。

按下 ⌘D 时书签就已经添加好了（Chrome 的做法）。随后从地址栏下方弹出的气泡只是给用户一个改名称的机会，点气泡外面关掉也会照常保存。

书签存在单独的 `Bookmarks.db` 里，每个书签自己存一份站点图标。**清除历史记录、清除浏览数据、移除网站数据都不会动到书签**，只有用户自己能删除书签。

## Considered Options

- **书签栏**（Chrome 的书签栏、Safari 的个人收藏栏）：会在工具栏下面再加一行，推翻「单行工具栏」（[ADR-0009](0009-unified-native-toolbar-chrome.md)），还会占掉一个本来就小的浮窗的内容区高度。
- **地址栏里放星标按钮**（Chrome 的做法）：地址栏的宽度预算已经很紧（[ADR-0016](0016-address-bar-as-container-of-siblings.md)），加星标就要整体重新测一遍收纳的临界宽度。用 ⌘D 加菜单项的文字（「添加书签…」变成「编辑书签…」）已经能表达「这一页是不是书签」。
- **空页面显示书签网格**（Chrome 新标签页、Safari 起始页的做法）：这次先不做，空页面保持装饰图形加热键速览。
- **文件夹**：书签一般只有二三十个，文件夹会带出子菜单、拖进拖出、删除文件夹时怎么处理里面的书签这一串问题。平铺列表就相当于只有根目录，以后要加文件夹也不会推翻现有数据。
- **允许同一网址存两个书签**（Safari 的做法）：在没有文件夹的平铺列表里，重复项只会带来混乱。
- **图标显示时去历史记录里找，或者按 origin 现场下载**：前一种会让清除历史记录把书签图标一起清掉，正是 [ADR-0030](0030-history-records-every-visit.md) 提醒过的那种跨删除路径的耦合；后一种每打开一次菜单就要发网络请求，没网时就是一排空白图标。
- **把书签放进 `History.db` 或 `config.toml`**：`HistoryStore` 发现文件损坏时会把整个文件挪到一边，书签不该跟着一起丢失。`config.toml` 存的是偏好设置，退出时会整份重写，设置窗口里还有一份它的镜像，而书签是带图标的用户内容。

## Consequences

- Ghost Mode 下「添加书签」「编辑书签」置灰，因为它们要弹出气泡，属于需要交互的操作（[ADR-0012](0012-ghost-mode-as-pure-invisibility.md)）。从书签打开网页仍然可用：它跟从历史记录打开一样，直接跳转，不退出隐身。Widget 已关闭时，先重新打开 Widget 再加载书签。
- 在书签窗口里新建书签时，网址按地址栏的规则解析，只接受 http/https。新建时拿不到页面标题，所以名称留空就用网址代替；书签也没有图标，等第一次访问这个网址时再补上。
- ⌘D、⌥⌘B 要加进 `DefaultHotkeys.reservedLocalMenuShortcuts`。
- 这次不做：托盘里的书签、从 Safari/Chrome 导入导出。以后真要做导入，只做「导入 HTML 书签文件」：这种格式两个浏览器都能导出，读取它也不需要任何系统权限。
