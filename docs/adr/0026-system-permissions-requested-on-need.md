# 系统权限在需要时才请求，幽灵模式只自动请求一次辅助功能

> 辅助功能那部分已被 [ADR-0028](0028-input-monitoring-only-for-typing-like-combos.md) 取代：视频控制要的是**输入监控**，而且只有绑了不带 ⌃/⌘ 的组合键时才需要。「用到时才请求、只自动请求一次、已获得就不出现」的原则不变。

Mochi 用到这些系统权限：辅助功能（视频控制，以及轻按/连按触发的热键传递，要靠它听到其他应用里的按键），摄像头和麦克风（网页用），下载文件夹（下载默认存到那里，实测第一次下载就会弹框）。组合键全局热键、把按键送进 web view 都不需要权限。原则是：**用到时才请求、请求过不再重复弹、已经获得就不出现任何说明或按钮**。没获得时，设置里对应的位置给出说明和按钮：系统还没问过就「请求权限」，问过被拒就「打开系统设置」（系统只肯弹一次框）。授权后即时生效，不需要重启。

辅助功能的系统授权框会抢焦点，跟 [ADR-0012](0012-ghost-mode-as-pure-invisibility.md)「Ghost Mode 永不获得焦点、不打扰」相冲突，但它又只在 Ghost Mode 里才用得上。我们刻意开一个口子：**第一次进入 Ghost Mode、并且绑了轻按/连按的键时，自动弹一次系统授权框，这一辈子只弹这一次**（标记存在 `UserDefaults`，不随 `config.toml` 或 `Application Support/Mochi` 删除而重置）。之后再缺权限，只在托盘菜单里出现一条提示、在设置的幽灵模式面板顶部显示说明，不再主动打断。

## Considered Options

- **Ghost Mode 里永远不弹，只靠设置里的按钮**：默认配置就绑了右 ⌥ 轻按，新用户按了没反应，也不知道为什么。
- **每次启动后第一次进入 Ghost Mode 都弹**（#79 原来的做法，标记只在内存里）：用户已经拒绝过，还会被反复打扰。
- **用系统通知提示**：为了提示缺一项权限，又去申请另一项权限，自相矛盾。

第一次往下载文件夹写入也走同一个口子：Ghost Mode 下网页发起的下载照常存到默认位置，如果恰好是有史以来第一次，系统会弹一次框。另两条路都更糟——放弃这次下载会让文件莫名消失，改存到别处会让同一个「下载位置」设置在两种模式下不一样。

摄像头、麦克风不需要这个口子：网页真正开始采集时由 macOS 自己弹框，系统也只弹一次；Ghost Mode 下 Widget 页面的请求本来就直接拒绝（见 [ADR-0027](0027-page-permission-per-website.md)）。

## Consequences

- 下载文件夹属于「文件和文件夹」类权限，**系统不提供查询**，只有真的去访问才知道，而访问本身就会触发弹框。所以它没法像其他几项那样「已获得就隐藏」：Mochi 记下最近一次写入下载文件夹的结果，权限错误时在「通用 → 下载位置」旁边显示提示和「打开系统设置」，下一次写入成功就收起。Normal Mode 下载因此失败时当场提示，并提供「存到其他位置…」（用户在存储面板里亲手选的位置不受限制）；Ghost Mode 下只记下失败、不打扰。
- 系统框没被回答之前，访问下载文件夹的调用一直卡着。这个访问不能放在主线程上，否则第一次下载会让整个 Mochi 无响应。

- 系统权限由 TCC 按 bundle id 和代码签名记录，**不随卸载、不随删除 Mochi 的数据而消失**；要清除只能 `tccutil reset All com.daidalma.mochi`，或在系统设置里移除。这写进 README 的卸载说明。
- 我们没有证书，用 ad-hoc 签名（[ADR-0014](0014-packaging-and-distribution.md)），代码签名要求就是这一份二进制的 cdhash。升级到新版本后，系统设置里辅助功能的开关**看着还开着，实际已经失效**，Mochi 也区分不出「关着」和「开着但签名对不上」。只能靠没权限时的说明文字兜底：「如果系统设置里已经打开，请先移除 Mochi 再重新添加」。等将来有了正式证书才能根治。（这一条按 ad-hoc 签名的已知行为推断，还没在 Mochi 的升级路径上实测。）

## 后续

- 升级陷阱已实测（2026-10-12，macOS 26.5，0.2.1 → 开发版）：升级后系统设置里辅助功能的开关仍显示打开，`AXIsProcessTrusted()` 却返回 false；在系统设置里关掉再打开**无效**，移除 Mochi 再重新添加才恢复——与上面说明文字的指引一致。同一个 cdhash 机制同样适用于输入监控。
