# 历史记录窗口里也能清除，默认只勾「历史记录」

#110 让「历史记录」菜单里的「清除浏览数据…」跳到设置窗口，在「隐私与安全性」面板上弹出对话框，理由是对话框只该放在一个地方。可在历史记录窗口里想清历史时，这个跳转就很突兀：人已经在看历史了，却要被带到另一个窗口去。现在历史记录窗口的工具栏里，搜索框左边（Safari 也放在这个位置）有一个**「清除历史记录…」**。它弹出的就是设置里**同一个**「清除浏览数据」对话框，以 sheet 的形式挂在历史记录窗口上，时间范围和可勾选的各项都一样，只有一处不同：**默认只勾「历史记录」**。

## Considered Options

- **跟菜单一样跳到设置窗口**：保住了「一个地方」，但把用户带离了正在看的窗口。
- **原样照搬设置里的默认勾选**（历史记录、Cookie 和网站数据、缓存）：按钮上写的是「清除历史记录…」，用户预期的就是清历史。照原默认清下去，会顺手把各个网站的登录都退掉。
- **单独做一个只清历史的简单确认框**：功能上做得到，但用户会看到两个长得不一样的清除对话框，要按时间范围清，或者一并清网站数据时，又得回到设置里。

## Consequences

- 这个对话框现在有两个入口（设置和历史记录窗口），初始勾选由入口决定；「历史记录」菜单里的「清除浏览数据…」照旧打开设置里的那一个，默认勾选也不变。
- 清除走的还是 `SettingsController.clearBrowsingData`，清除的语义只有一处定义。
