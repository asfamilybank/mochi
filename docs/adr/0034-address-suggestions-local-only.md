# 地址栏建议只用本地数据，行内补全取排名最高的网址

在智能地址栏里输入时，Mochi 会给出**地址栏建议**，分行内补全和下拉列表两部分。建议**只来自本地的书签和历史记录**，用户输入的内容不会发给搜索引擎。[ADR-0030](0030-history-records-every-visit.md) 已经定下「补全只从访问表计算」：建议每次都从访问记录现算，不另建缓存。所以清除历史记录后，建议自然跟着变，不需要再接任何删除路径。

- **下拉列表**照 Chrome 的样子，是一个单列表，最多 8 行。第一行固定写出「按回车会发生什么」：要么打开行内补全出来的网址，要么按地址栏现有规则判断成网址或搜索，比如「用 Google 搜索 xxx」。下面是书签和历史记录混排的匹配结果，同一个网址只占一行。如果这个网址有书签，就显示书签的名称，并带一个书签标记。
- **匹配**：输入里的每个词，都要在网址（去掉 `https://` 和 `www.`）、标题或书签名称里找到一个以它开头的词。
- **排序**：按网址把访问记录聚合起来算 frecency，越近的访问权重越高；有书签的网址再加一个固定分。
- **行内补全**：在「网址以输入开头」的条目里取排名最高的那条，补出来的部分处于选中状态。一条都没有时不补全。按 ⌫ 或 ⌦ 之后暂停补全，直到用户再敲一个新字符。
- **键盘**：↑↓ 在列表里移动，输入框同步显示选中行的网址；回车打开选中的那一行。Esc 分三步：
  1. 关掉下拉列表，撤销补全出来的部分。
  2. 输入框恢复成原来的网址；在空页面上则清空。
  3. 退出编辑。

  某一步没有可做的事时就直接跳到下一步。
- **还没开始输入时**（点进地址栏，网址处于全选状态），下拉列表按书签自己的顺序列出全部书签；没有书签就不弹出下拉。
- 下拉列表左边跟地址栏对齐，宽度取地址栏宽度和 400pt 中较大的那个，可以超出 Widget 窗口的边缘。

## Considered Options

- **搜索引擎的远程建议**（Safari 的「包括搜索引擎建议」默认是开着的）：每敲一个字，就会把还没输完的内容（包括还没敲完的网址）发给第三方。这跟项目的一贯立场相冲突，favicon 不用第三方服务也是同样的理由。另外，远程建议是网络请求，要处理防抖和乱序返回。如果以后要做，单独决定，并带上 Safari 的那个开关。
- **行内补全只补到主机名**（输入里没有 `/` 时，`git` 只补成 `github.com`）：这能避开 Chrome 的老问题，也就是敲 `y` 直接补成某个具体视频的网址。但这样一来，「补全的是最可能去的地方」就打了折扣。最后选择**直接补成排名最高的网址**，接受这个代价。被否决的另一种做法是 Chrome 的：只补全「在地址栏里亲手敲过」的网址。这需要给访问记录加一列来源，`visits` 表里没有这一列。
- **Safari 式分区下拉**（「最佳匹配」「书签和历史记录」各带小标题）：没有远程建议之后，分区基本只剩一组，小标题只会增加干扰。
- **任意子串匹配**（历史记录窗口的搜索就是这样）：补全要的是敲两三个字就命中，子串匹配会带出大量无关结果。历史记录窗口的目的是「找东西」，所以那边用子串匹配仍然是对的。
- **⇧⌫ 从建议里删掉一条历史记录**（Chrome 的做法）：这是一个看不见的破坏性操作，实际删除的是这个网址的全部访问记录。要删就去历史记录窗口删。

## Consequences

- 地址栏现在完全不处理 Esc，要从零补上这三步。
- `visits` 表每次访问一行，没有按网址汇总的统计，frecency 每次查询都要聚合计算。如果以后为了性能加缓存，就必须接上历史记录的所有删除路径，包括逐条删除、清除历史记录、清除浏览数据和保留期限。
- 实现时（#122）定下了两条范围：
  - **只看最近 90 天的访问**。历史记录很多时（一年 30 万次访问，每次都是不同的网址），每敲一个字都扫一遍全年要 100 多毫秒，超出了一次按键能用的时间；限定在 90 天内大约是 30 毫秒。frecency 本来也主要看最近的访问，Chrome 的地址栏同样只考虑近期常去的网页。只在 90 天前访问过的网页不会出现在建议里，但历史记录窗口里照样搜得到。保留期限比 90 天短时，以保留期限为准。
  - **先粗筛，再精确匹配**。SQLite 只负责粗筛：每个词出现在网址或标题里的任意位置就算，按 frecency 取前 500 条。词首规则由 `AddressEditingSession` 在 Swift 里判断。
- 词首规则对中日韩文字放宽了：词不以拉丁字母或数字开头时，出现在任意位置都算命中。中文没有空格，按「词首」理解只会让「教程」匹配不到「廖雪峰Git教程」。`hub` 不命中 GitHub 这类拉丁文字的规则不变。
