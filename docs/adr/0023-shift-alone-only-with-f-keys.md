# 组合键单带 ⇧ 只放行 F 键

[ADR-0022](0022-trigger-key-three-kinds.md) 定下组合键至少要带 ⌃⌥⌘ 之一，并豁免「F 键、方向键这类本身不产生字符的键」单带 ⇧。实现 #89 时发现这条豁免放得太宽。

## 决定

只有 F1–F20 可以单带 ⇧ 组成组合键。⇧ 加方向键、Home/End、空格等一律拒绝，跟 ⇧ 加字母一样，录制时行内提示「组合键至少要有 ⌃ ⌥ ⌘ 之一」。

理由：「不产生字符」不是该用的判据，该问的是「这个组合在别的 app 里有没有用」。⇧ 加方向键和 ⇧Home/⇧End 是所有 app 里选择文字的操作，⇧ 空格也是常见输入；作为 Carbon 全局热键被吞掉，代价跟 ⇧ 加字母一样大。F 键单带 ⇧ 在绝大多数 app 里没有含义。

## Consequences

- 已经存进配置的 ⇧ 加方向键之类的绑定照常生效（同 ADR-0022 对旧绑定的处理），只是不能再新录。
