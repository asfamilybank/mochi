# Mochi 是什么，不是什么

Mochi 长得像浏览器，也能打开任何网页，但它不是用来替代 Safari 或 Chrome 的。这一页讲清楚它的定位，以及它为什么少了一些浏览器常见的功能。

## Mochi 想做好的那一件事

Mochi 把一个网页变成桌面上的浮窗：你在别的应用里工作，它待在屏幕一角，你不用切换过去，也能用按键控制它。最典型的用法是边工作边看视频或直播。

Mochi 的大部分设计都从这个场景出发：

- 窗口要能浮在最上层，又不挡住你在别的应用里的操作，这就是[幽灵模式](../how-to/ghost-mode.md)。
- 有人走过来时，要能一下子让窗口消失，这就是[隐藏窗口](../how-to/hide-window.md)，相当于老板键。
- 你的焦点一直留在别的应用里，所以按键要在别的应用里也能被 Mochi 听到，这就是[视频控制](../how-to/video-control.md)和[热键传递](../how-to/hotkey-forwarding.md)。

## 为什么一个窗口只放一个网页

Mochi 只有一个窗口，窗口里只放一个网页，没有标签页，也不能同时开多个窗口。

- **热键要控制的对象始终明确**。你在别的应用里按下暂停时，Mochi 不用猜你指的是哪个标签页、哪个窗口，作用的永远是那一个网页。
- **浮窗本来就只该放一样东西**。放在屏幕角落的小窗口里，一次只看得过来一个网页。
- **先把核心用法做扎实**。标签页和多窗口会带来一大串管理上的问题，目前的版本有意不做。

因此，网页里那些本该在新窗口打开的链接，在 Mochi 里会直接在当前窗口打开，替换掉原来的网页。

唯一的例外是登录小窗：网页为了让你登录（比如用微信或 Google 账号登录）而打开的小窗口。它依赖原来的网页才能完成登录，所以 Mochi 会把它单独开出来，登录完它会自己关掉。它不是第二个 Mochi 窗口，也不能进入幽灵模式。

## 为什么关闭窗口就是真的关闭

在很多应用里，关闭窗口只是把它收起来。Mochi 不一样：关闭窗口后网页停止运行，再打开时从头加载。

这是因为“暂时看不见”已经有专门的办法了：悬浮模式和幽灵模式下的隐藏窗口。隐藏时窗口还在，网页继续运行，只是视频和声音会暂停。关闭留给“现在不用了”的时候：网页不再运行，也不再占用电脑的资源。

两种需求各用一种办法，就不会出现“以为关掉了，其实还在后台出声”或者“以为藏起来了，其实已经没了”这类情况。关闭窗口之后，Mochi 本身仍然在菜单栏和程序坞里，随时可以重新打开窗口，位置和大小都会保留。具体操作见[摆放和关闭窗口](../how-to/window-placement.md)。

## 为什么没有扩展、书签栏、书签文件夹和同步

- **浏览器扩展**：Mochi 目前不能安装浏览器扩展，包括 Chrome 插件。想调整某个网站，可以用 Mochi 自带的脚本和样式表，见[用脚本和样式表调整网页](../how-to/scripts.md)。
- **书签栏和书签文件夹**：Mochi 窗口只放一个网页，书签在这里只做一件事：把当前网页换成另一个。常看的网站一般也就二三十个，一份可以手动排序的书签列表就够用，不需要书签栏，也不需要文件夹。书签可以从「书签」菜单、地址栏和书签窗口打开。
- **同步**：Mochi 没有账号，也没有同步服务。历史记录、书签和设置只存在你这台 Mac 上，不会同步到其他设备。

## 为什么只有 macOS 版

Mochi 是专门为 macOS 写的应用，直接用 macOS 自己的窗口、菜单栏和按键能力来实现幽灵模式、[全局热键](../how-to/global-hotkeys.md)这些功能，没有为了跨平台做妥协。所以它只能在 Mac 上运行，而且需要 macOS 26 或更高版本、Apple 芯片的 Mac。目前没有其他平台版本的时间表。

## 适合和不适合的场景

**适合**：

- 边工作边看视频、直播或者网课，想让它待在角落里不碍事。
- 想在不切换应用的情况下暂停、快进、后退视频。
- 有人走过来时，想一键把窗口藏起来。
- 想把某个网页（比如监控面板、音乐播放器）一直挂在桌面上。

**不适合**：

- 当作日常主力浏览器：同时开很多网页、管理一堆书签、在多台设备之间同步。这些用 Safari 或 Chrome 更合适。
- 需要依赖浏览器扩展才能正常使用的网站。
