# Mochi 记下什么、不发给谁

Mochi 会在你的 Mac 上记下一些东西，好让你找回看过的网页、少敲几个字。本页讲它记下了什么、哪些东西不会离开你的电脑，以及三种容易混在一起的「权限」和「数据」。

## 记下了什么

- **历史记录**：你在 Mochi 窗口里访问过的网页，每次访问记下网址、当时的标题和网站图标。哪些访问会记、哪些不会，见[查找和管理历史记录](../how-to/history.md#哪些访问会被记下)。
- **书签**：你自己存下的网页，连同各自的网站图标。
- **设置**：包括你给哪些网站开了摄像头、麦克风。
- **网站数据**：网站自己存进来的 Cookie、缓存等，跟在任何浏览器里一样。

这些都只存在你这台 Mac 上。Mochi 没有账号，也没有同步功能，不会把它们上传到任何地方。具体存在哪个文件夹、删掉会怎样，见 [Mochi 存放的数据与系统权限](../reference/data-and-permissions.md#数据存在哪里)。

## 地址栏建议只来自本机

在地址栏里输入时，下拉列表和直接补进输入框的网址，只来自你本机的书签和历史记录。你敲下的每一个字都留在本机，按 ↩（Return）之前不会发给搜索引擎或任何人。

很多浏览器会把你正在输入的内容实时发给搜索引擎，换回“搜索建议”，这意味着连还没敲完、最后决定不打开的网址，搜索引擎也都看得到。Mochi 不这样做。代价是建议里只有你自己看过或存过的网页，没有搜索引擎的热门词。

因为建议是每次输入时从历史记录和书签里现算出来的，删掉历史记录后，建议马上就跟着变，不会有别处留着的副本。

按 ↩ 之后，如果你输入的不是网址，Mochi 才会用你在「设置 › 通用」里选的搜索引擎去搜索它，这跟你自己打开搜索引擎的网站输入是一样的。

## 网站图标不经过第三方

地址栏、历史记录、书签里的网站图标，是 Mochi 自己下载的：按网页里写明的图标地址去取，网页没写明时，就去这个网站自己的 `/favicon.ico` 取，不经过任何第三方图标服务。

有些浏览器或应用图省事，会用第三方提供的图标服务来取网站图标。那样的话，你每打开一个网站，那家服务就会知道一次，相当于凭空多出一份你的浏览记录。Mochi 不用这类服务。下载图标时也不带 Cookie，网站没法把这次下载跟你的登录状态对上。

图标下载下来之后跟历史记录、书签存在一起，所以打开历史记录窗口、书签窗口或菜单时，不会再发出任何网络请求。

除了你打开的网页和这些网站图标，Mochi 自己不发出网络请求：没有使用统计，也不会自动检查更新。

## 网页权限、系统权限和网站数据

这三样名字相近，管的却是完全不同的东西：

| | 是什么 | 谁决定 | 在哪里管理 |
|---|---|---|---|
| 网页权限 | Mochi 允许哪个网站使用摄像头、麦克风 | 你，在 Mochi 里 | 「设置 › 网站 › 摄像头」「设置 › 网站 › 麦克风」；也可以在「管理网站和数据…」里点「重置权限」 |
| 系统权限 | macOS 允许 Mochi 这个应用做什么，比如辅助功能、摄像头、麦克风、文件和文件夹 | 你，在系统设置里 | 「系统设置 › 隐私与安全性」，Mochi 自己改不了 |
| 网站数据 | 网站存在 Mochi 里的 Cookie、缓存等，登录状态就在里面 | 网站自己存进来 | 「设置 › 隐私与安全性 › 网站数据」里的「管理网站和数据…」「清除浏览数据…」 |

几个容易混淆的地方：

- **网页要用摄像头时，网页权限和系统权限两道都要过**。系统权限是总开关：系统不让 Mochi 用摄像头，任何网站都用不了。网页权限是分到每个网站的开关：系统允许了，Mochi 还会再看这个网站能不能用。
- **网页权限按主机名分，网站数据按整个域名分**。`meet.google.com` 和 `calendar.google.com` 在网页权限里是两个网站，它们的网站数据却都算在 `google.com` 名下，只能一起删。见[清除浏览数据和网站数据](../how-to/clear-data.md#为什么删除一个子域名会连整个域名一起删)。
- **删除网站数据不会动网页权限，反过来也一样**。退出某个网站的登录，不会让它丢掉摄像头授权；重置它的权限，也不会让你退出登录。
- **卸载 Mochi 或删除它的数据，不会清掉系统权限**。系统权限由系统按应用保管，要清除见[卸载 Mochi](../how-to/uninstall.md#第三步清除系统权限可选)。

每项系统权限什么时候需要，见 [Mochi 存放的数据与系统权限](../reference/data-and-permissions.md#系统权限)。

## 为什么清除浏览数据不会动书签

历史记录、Cookie、缓存都是你浏览时自动留下的痕迹，清除它们是为了抹掉痕迹，或者让某个网站重新开始。书签不一样，它是你特意存下来的东西。要是清一次痕迹就把书签一起清掉，这个按钮就没人敢点了。

所以书签存在单独的地方，连网站图标也是自己存一份，不借用历史记录里的。清除历史记录、清除浏览数据、删除网站数据，都碰不到书签；只有你自己在书签窗口里删除，或者在添加书签的气泡里点「移除」，才能删掉它。
