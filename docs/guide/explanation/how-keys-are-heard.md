# 按键是怎么被 Mochi 听到的

你在别的应用里工作时按下的键，本来只会交给你正在用的那个应用。Mochi 要在这时听到你的按键，只有两种办法：一种是“占用”，一种是“旁听”。这一页讲这两种办法有什么区别，为什么有的键会在别的应用里失灵，为什么有的键需要权限，以及默认按键为什么是现在这样。

## “占用”和“旁听”

**占用**：Mochi 事先告诉系统“这个组合归我”。之后不管你在哪个应用里按下它，系统都直接交给 Mochi，你正在用的应用根本收不到。用这种办法的是：

- 全局热键：「切换幽灵模式」（默认 ⌥G，即 Option + G）和「隐藏窗口」（默认 ⌥H）；
- 热键传递里，触发键是组合键的映射。

**旁听**：Mochi 不向系统要任何组合，只是在一旁看着按键经过。按键照常交给你正在用的应用，跟没装 Mochi 时一模一样，Mochi 只是顺便知道你按了什么。用这种办法的是：

- 视频控制的全部按键，包括组合键；
- 热键传递里，触发键是轻按或连按两次的映射。

而且 Mochi 只在幽灵模式下旁听，普通模式下它不看你的键盘。

两种办法各有代价：占用的组合在别的应用里会失灵；旁听的按键会在你正在用的应用里照常起作用，比如把视频控制设成 ⌥P，在输入框里按它，除了切换播放，还会打出一个“π”。

## 为什么占用会让这个组合在其他应用里失灵

占用是向系统登记的，登记一直持续到 Mochi 退出，或者你在设置里把这个组合改掉、删掉。系统不知道 Mochi 此刻用不用得上它，只管把它交给 Mochi。所以：

- 普通模式下按 ⌥H，Mochi 什么也不做，但别的应用照样收不到；
- 窗口关着、Mochi 只留在菜单栏里时，⌥G、⌥H 也照样被占着；
- 在常用的英文键盘布局下，⌥G、⌥H 本来分别打出“©”“˙”，Mochi 运行时这两个字符就打不出来了。

占用还有一个看不见的地方：系统只会拒绝两个应用登记同一个全局热键，并不知道别的应用菜单里用了哪些快捷键。所以你把全局热键设成某个应用菜单里的快捷键时，Mochi 不会收到任何提示，那个应用里的这个快捷键却从此失灵了。

想要哪个组合不再失灵，就把它改掉，或者把映射的触发方式换成轻按、连按两次，见[修改全局热键](../how-to/global-hotkeys.md)和[把热键变成网页按键](../how-to/hotkey-forwarding.md)。

## 为什么有的组合键需要辅助功能权限

只带 ⌥ 或 ⇧（Shift）的组合键，在系统看来是在打字：⌥P 打出“π”，⇧ 加字母打出大写字母。为了防止有应用偷偷记下你打的字，系统不让一个应用旁听别的应用里的打字，除非你在「系统设置 › 隐私与安全性 › 辅助功能」里明确允许了它。

带 ⌃（Control）或 ⌘（Command）的组合键是命令，不是打字；单独按一下修饰键什么字也打不出来。这两种系统都允许旁听，不需要任何权限。占用的组合是 Mochi 正式向系统登记的，也不需要权限。

所以，只有当你把视频控制的某个功能设成了不带 ⌃ 也不带 ⌘ 的组合键（比如 ⌥P、⇧F5）时，Mochi 才需要辅助功能权限；其余情况一概不需要。怎么授予，见[故障排除](../how-to/troubleshooting.md#幽灵模式下视频控制的组合键如-p没反应)；为什么每次升级后都要重新添加，见[为什么第一次打开会被拦下](unsigned-app.md#为什么每次升级后都要把辅助功能移除再重新添加)。

出于同样的原因，别的应用正在让你输入密码时，系统连有权限的应用也不让旁听普通按键，视频控制的组合键这时暂时不起作用；单独按修饰键不算打字，轻按和连按两次照常可用。

## 为什么视频控制默认用轻按和连按两次

视频控制要的是：你在编辑器里写代码、在游戏里操作、在会议里打字时，随时都能按，而且按了之后你手上的事不受影响。单独轻按一颗修饰键正好满足：

- 它在任何应用里都不打出字符、不移动光标，旁听时不会在你正在用的应用里留下任何痕迹；
- 它不需要占用，也不需要任何权限；
- Mochi 能分清左右两侧的修饰键，默认只用右侧的，你平时用左手按的 ⌘、⌥ 完全不受影响。

具体选了右 ⌥（右侧的 Option 键）和右 ⌘（右侧的 Command 键），是因为其他修饰键有副作用：很多中文输入法默认用 ⇧ 切换中英文，轻按右 ⇧ 会顺带把输入法切掉。可是只用两颗键要放下三个功能，所以后退、前进用了连按两次：轻按右 ⌥ 播放/暂停，连按两次右 ⌘ 后退，连按两次右 ⌥ 前进。

代价是右 ⌥ 两用：轻按之后，Mochi 要等约 0.3 秒、确认你不是要连按两次，才执行播放/暂停。想让它立刻响应，把「前进」改到别的键上就行。

轻按也不会被你打字时的按键误触发：只有单独按下又松开、中间没有按别的键时才算一次轻按。你按住右 ⌥ 再按一个字母打特殊字符，不算轻按。

## 为什么全局热键只能是组合键

轻按和连按两次只能靠旁听来识别。如果「切换幽灵模式」能设成轻按，Mochi 就得在普通模式下也一直旁听你的键盘，才知道什么时候该进入幽灵模式。Mochi 选择不这样做：它只在幽灵模式下旁听，普通模式下不看你的键盘，所以全局热键只能是占用的组合键。

## 为什么组合键至少要带 ⌃ ⌥ ⌘ 之一

被占用的组合会在所有应用里失灵。如果允许把单独一个字母、或者 ⇧ 加一个字母设成热键，这个字母或它的大写就在所有应用里都打不出来；⇧ 加方向键是选择文字，占用了也一样碍事。所以组合键至少要带 ⌃、⌥、⌘ 之一。唯一的例外是 F1 到 F20 这些功能键：它们只带 ⇧ 时在绝大多数应用里没有用处，可以只带 ⇧。

视频控制的组合键虽然不占用，录制时也按同样的规则。

## 为什么默认热键避开了系统常用的快捷键

占用的组合会从每一个应用手里拿走，所以默认热键要挑一个大家几乎用不到的组合。macOS 里很多看起来冷门的组合其实都有用处：比如 ⌥⌘H 是每个应用里的「隐藏其他」，⇧⌘G 是访达里的「前往文件夹」，也是很多应用里的「查找上一个」。默认热键要是用了它们，这些功能就会在所有应用里失灵。

所以现在的默认热键是只带 ⌥ 的 ⌥G 和 ⌥H。代价是它们在其他应用里打不出“©”和“˙”，这两个字符平时很少用到；需要的话，把热键改成别的组合即可。
