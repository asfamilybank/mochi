# 菜单与托盘菜单

这一页列出 Mochi 菜单栏里的每个菜单项，以及菜单栏里 Mochi 图标（托盘图标）的菜单，每一项一句话说明。

快捷键用的符号：⌘（Command）、⌥（Option）、⇧（Shift）。菜单快捷键只在 Mochi 是当前应用时有效。

## 菜单栏

### 什么时候菜单项是灰的

作用于网页窗口的菜单项，也就是「显示」菜单里的全部项，「历史记录」菜单里的「返回」「前进」，以及「书签」菜单里的「添加书签…」，在这两种情况下是灰的：

- 窗口已经关闭。
- 窗口处于幽灵模式。要用这些项，先退出幽灵模式。

「文件 › 打开位置…」在窗口关闭时也能用，它会先重新打开窗口；幽灵模式下同样是灰的。

除了下面列出的项，macOS 还会往一些菜单里自动加上系统通用的项，比如「编辑」菜单里的听写、表情与符号，「窗口」菜单里的窗口列表。这些项跟在其他应用里一样，这里不逐个说明。

### Mochi

| 菜单项 | 快捷键 | 作用 |
|---|---|---|
| 「关于 Mochi」 | | 显示版本号等信息。 |
| 「设置…」 | ⌘, | 打开设置窗口。 |
| 「服务」 | | macOS 的服务子菜单。 |
| 「隐藏 Mochi」 | ⌘H | macOS 的标准操作，把 Mochi 的所有窗口暂时藏起来，切到别的应用。它不是幽灵模式下的「隐藏窗口」（老板键）。 |
| 「隐藏其他」 | ⌥⌘H | 藏起其他所有应用的窗口。 |
| 「全部显示」 | | 重新显示被藏起来的应用。 |
| 「退出 Mochi」 | ⌘Q | 完全退出 Mochi。 |

### 文件

| 菜单项 | 快捷键 | 作用 |
|---|---|---|
| 「打开位置…」 | ⌘L | 把 Mochi 窗口带到最前面，选中地址栏，可以直接输入网址。窗口已经关闭时，先重新打开它。 |
| 「关闭窗口」 | ⌘W | 关闭最前面的 Mochi 窗口。关闭网页窗口是真的关闭，网页会停止运行，见[摆放和关闭窗口](../how-to/window-placement.md#关闭窗口)。 |

### 编辑

| 菜单项 | 快捷键 | 作用 |
|---|---|---|
| 「撤销」 | ⌘Z | 撤销上一步输入。 |
| 「重做」 | ⇧⌘Z | 重做刚撤销的操作。 |
| 「剪切」 | ⌘X | 剪切选中的内容。 |
| 「拷贝」 | ⌘C | 拷贝选中的内容。 |
| 「粘贴」 | ⌘V | 粘贴。 |
| 「粘贴并匹配样式」 | ⌥⇧⌘V | 只粘贴文字，不带原来的格式。 |
| 「删除」 | | 删除选中的内容。 |
| 「全选」 | ⌘A | 全选。 |

这些项作用于你正在输入的地方，比如地址栏、网页里的输入框、设置窗口里的文本框。

### 显示

| 菜单项 | 快捷键 | 作用 |
|---|---|---|
| 「停止」 | ⌘. | 停止加载当前网页。只在网页加载时可用。 |
| 「重新载入页面」 | ⌘R | 重新加载当前网页。 |
| 「放大」 | ⌘+ | 放大网页，每次 10%。 |
| 「缩小」 | ⌘- | 缩小网页，每次 10%。 |
| 「实际大小」 | ⌘0 | 把网页恢复成 100%。 |

### 历史记录

| 菜单项 | 快捷键 | 作用 |
|---|---|---|
| 「返回」 | ⌘[ | 回到上一个网页，跟工具栏的「后退」按钮一样。没有可以回去的网页时是灰的。 |
| 「前进」 | ⌘] | 前进到下一个网页，跟工具栏的「前进」按钮一样。 |
| 最近访问的网页 | | 先列出今天最近访问的网页（最多 15 条），再按天列出之前 6 天里有访问的日子，每天一个子菜单。选一个就在窗口里打开它。 |
| 「显示全部历史记录」 | ⌘Y | 打开历史记录窗口；它已经在最前面时，再按一次就关掉。 |
| 「清除浏览数据…」 | | 打开清除浏览数据的对话框，跟「设置 › 隐私与安全性」里的是同一个。 |

从历史记录打开网页时，窗口已经关闭就会重新打开并直接加载它；窗口处于幽灵模式时会直接跳转，不会退出幽灵模式。

### 书签

| 菜单项 | 快捷键 | 作用 |
|---|---|---|
| 「添加书签…」 | ⌘D | 把当前网页存成书签，并弹出编辑框，可以改名字。当前网页已经是书签时，这一项显示为「编辑书签…」，只打开编辑框。只在打开了网页时可用，空页面上是灰的。 |
| 「显示所有书签」 | ⌥⌘B | 打开书签窗口；它已经在最前面时，再按一次就关掉。 |
| 你的书签 | | 按你排好的顺序列出全部书签，选一个就在窗口里打开它。 |

从书签打开网页的规则跟从历史记录打开一样。

### 窗口

| 菜单项 | 快捷键 | 作用 |
|---|---|---|
| 「最小化」 | ⌘M | 把最前面的窗口收进程序坞。 |
| 「缩放」 | | 在窗口当前大小和适合屏幕的大小之间切换。 |

下面还有 macOS 自动加上的项，比如移动与调整大小、窗口列表。

### 帮助

| 菜单项 | 作用 |
|---|---|
| 「Mochi 帮助」 | 在浏览器里打开本手册。 |
| 「反馈问题…」 | 在浏览器里打开 Mochi 在 GitHub 上的问题反馈页面。 |

「帮助」菜单顶部的搜索框是 macOS 自带的，可以搜索所有菜单项。

## 托盘菜单

点菜单栏右侧的 Mochi 图标，会弹出下面这个菜单。Mochi 运行期间这个图标一直在，不管窗口是开着、关着，还是处于幽灵模式。

<!-- 📷 images/tray-menu.png — 托盘菜单，点开菜单栏里的 Mochi 图标后的样子（需人工截图） -->

| 菜单项 | 右侧显示的按键 | 作用 |
|---|---|---|
| 「打开窗口」 | | 窗口关闭时重新打开它；窗口开着时把它带到最前面；窗口处于幽灵模式时，退出幽灵模式。 |
| 「幽灵模式」 | ⌥G | 进入或退出幽灵模式。处于幽灵模式时前面有勾。窗口关闭时是灰的。 |
| 「隐藏窗口」 | ⌥H | 让窗口完全看不见，相当于老板键，再点一次让它回来。窗口隐藏时前面有勾。只在幽灵模式下可用，普通模式下是灰的。 |
| 「视频控制需要辅助功能权限…」 | | 只在视频控制用了需要辅助功能权限的按键、而 Mochi 还没有这项权限时出现。第一次点会请求权限，之后再点会打开系统设置。 |
| 「设置…」 | ⌘, | 打开设置窗口。 |
| 「关于 Mochi」 | | 显示版本号等信息。 |
| 「退出」 | ⌘Q | 完全退出 Mochi。 |

「幽灵模式」和「隐藏窗口」右侧显示的是你当前设定的全局热键，在「设置 › 幽灵模式 › 全局热键」里改过之后，这里也会跟着变。这两个热键在任何应用里都能按；「设置…」和「退出」右侧的 ⌘, 和 ⌘Q 只在 Mochi 是当前应用时有效。

幽灵模式下点击会穿过窗口，这个菜单是随时都点得到的那条退路：点「幽灵模式」或「打开窗口」都能退出幽灵模式。
