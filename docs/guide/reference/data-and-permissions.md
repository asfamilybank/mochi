# Mochi 存放的数据与系统权限

本页列出 Mochi 在你的电脑上存了哪些东西、存在哪里，以及它在什么时候需要哪项系统权限。

## 数据存在哪里

这些数据都只存在你这台 Mac 上，Mochi 没有同步功能。路径里的 `~/Library` 在访达里默认是隐藏的，可以在访达里选择「前往 › 前往文件夹…」，或者按 ⇧⌘G（Shift + Command + G），粘贴路径打开。

| 位置 | 装的是什么 | 删掉会怎样 |
|---|---|---|
| `~/Library/Application Support/Mochi/config.toml` | 你的全部设置：热键、映射、自定义脚本和样式表、哪些网站可以用摄像头和麦克风，还有窗口的位置和大小、上次访问的网页 | 下次打开时所有设置恢复默认 |
| `~/Library/Application Support/Mochi/History.db` | 历史记录，连同每条记录的网站图标 | 历史记录全部消失，地址栏建议里也不再有来自历史记录的网址 |
| `~/Library/Application Support/Mochi/Bookmarks.db` | 书签 | 书签全部消失 |
| `~/Library/Caches/com.daidalma.mochi` | 网站缓存：缓存的网页文件和图片 | 不会退出登录，网站下次打开时可能稍慢 |
| `~/Library/WebKit/com.daidalma.mochi` | 网站存在本机的其他数据，一部分网站的登录态也在这里 | 可能退出部分网站的登录，网站保存在本机的偏好也会丢失 |
| `~/Library/HTTPStorages/com.daidalma.mochi.binarycookies` | 网站的 Cookie，也就是大多数网站的登录态 | 退出所有网站的登录 |
| `~/Library/Preferences/com.daidalma.mochi.plist` | 几个跟系统权限有关的小标记，比如 Mochi 是否已经自动请求过一次辅助功能权限 | 影响很小，一般不需要管它 |

使用这些数据时要注意：

- 设置请在设置窗口里改。Mochi 开着的时候手动改 `config.toml` 不会生效，Mochi 退出时还会把它整份重写。
- 历史记录、Cookie、缓存这些不用自己去删文件：选择「历史记录 › 清除浏览数据…」，或者在「设置 › 隐私与安全性 › 网站数据」里点「清除浏览数据…」「管理网站和数据…」，就能按时间范围或按网站清除。清除浏览数据不会动书签、设置和系统权限。
- 卸载时要删哪些位置，见[卸载 Mochi](../how-to/uninstall.md)。

## 系统权限

系统权限是 macOS 允许 Mochi 这个应用做的事，跟「设置 › 网站」里管的网页权限（Mochi 允许哪个网站用摄像头）是两回事。Mochi 只在用到时才申请，已经获得的权限不会再出现任何提示；缺少时，设置里对应的位置会给出说明和按钮：系统还没问过时是「请求权限」，问过被拒之后是「打开系统设置」（文件和文件夹只在往「下载」文件夹存文件被拒之后才提示，所以只有「打开系统设置」）。

| 系统权限 | 什么时候需要 | 什么时候申请 | 在哪里改 | 改了之后 |
|---|---|---|---|---|
| 辅助功能 | 只有视频控制里有不带 ⌃（Control）也不带 ⌘（Command）的组合键时才需要，比如 ⌥P（Option + P）、⇧F5（Shift + F5）。默认按键、轻按、连按两次、带 ⌃ 或 ⌘ 的组合键、全局热键、热键传递都不需要 | 绑了这种按键之后，第一次处在幽灵模式时，Mochi 自动请求一次，以后不会再自动请求。之后还缺的话，「设置 › 热键」顶部和托盘菜单里的「视频控制需要辅助功能权限…」会提示你 | 「系统设置 › 隐私与安全性 › 辅助功能」 | 打开后马上生效，不用重新打开 Mochi。每次升级 Mochi 后都要把它移除再重新添加，见[升级 Mochi](../how-to/upgrade.md#重新添加辅助功能权限) |
| 摄像头、麦克风 | 网页要用摄像头或麦克风时，比如开视频会议 | 网页第一次开始使用摄像头或麦克风时，系统会问一次。也可以在「设置 › 网站 › 摄像头」或「设置 › 网站 › 麦克风」顶部的提示里点「请求权限」 | 「系统设置 › 隐私与安全性 › 摄像头」「系统设置 › 隐私与安全性 › 麦克风」 | 被拒过之后再打开，要退出并重新打开 Mochi 才生效；正在用的时候关掉，也要重新打开 Mochi 才会被拒 |
| 文件和文件夹（下载文件夹） | 「设置 › 通用 › 下载 › 文件下载位置」选的是「下载」时。选「每次询问」或你自己选的文件夹不需要 | 第一次往「下载」文件夹存文件时，系统会问一次 | 「系统设置 › 隐私与安全性 › 文件和文件夹」 | 被拒过之后再打开，要退出并重新打开 Mochi 才生效 |

补充几点：

- 系统只会问一次。拒绝过之后，只能到系统设置里去改，Mochi 设置里的「打开系统设置」会直接带你过去。
- 在系统设置里改了摄像头、麦克风或文件和文件夹，系统提示要退出并重新打开 Mochi 时，请照做；只关掉窗口不算重新打开。见[故障排除](../how-to/troubleshooting.md#在系统设置里打开了摄像头麦克风或文件和文件夹权限mochi-里还是用不了)。
- 在幽灵模式下，以及悬浮模式下隐藏窗口时，网页的摄像头、麦克风请求会被直接拒绝，不会弹出询问；下载照常进行，如果文件要存进「下载」文件夹、而且恰好是第一次，系统仍会问一次。
- 公司或学校管理的 Mac 上，某些权限可能被管理策略锁定，你和 Mochi 都改不了，设置里会写明「受管理策略限制」。
- 这些权限由系统按应用保管，不随卸载 Mochi 或删除它的数据而消失。要清除，见[卸载 Mochi](../how-to/uninstall.md#第三步清除系统权限可选)。

## 不需要的权限

Mochi 不需要「输入监控」和「屏幕录制」。如果你在「系统设置 › 隐私与安全性 › 输入监控」里看到 Mochi 并且开关是关着的，不用打开它，这不影响任何功能。
