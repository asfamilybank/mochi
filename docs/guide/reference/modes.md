# 三种模式对照

Mochi 窗口有三种模式：

- **普通模式**：窗口平时的状态，跟一个普通的 macOS 窗口一样。
- **悬浮模式**：只剩网页内容，半透明，浮在最上层，但仍然可以点击、输入，跟普通窗口一样用。按 ⌥F（Option + F）进入或退出，见[用悬浮模式边看边用网页](../how-to/float-mode.md)。
- **幽灵模式**：网页浮在最上层、半透明，点击会穿过窗口，不打扰你在别的应用里的操作。按 ⌥G（Option + G）进入或退出，见[用幽灵模式让网页浮在最上层](../how-to/ghost-mode.md)。

悬浮模式和幽灵模式之间可以直接切换：在悬浮模式下按 ⌥G 进入幽灵模式，在幽灵模式下按 ⌥F 进入悬浮模式，不用先回到普通模式。

悬浮模式和幽灵模式里还有一个「隐藏窗口」状态，相当于老板键，表里单独标出它不一样的地方。在这两个模式之间切换时，窗口保持隐藏；回到普通模式时，窗口重新显示。见[一键隐藏窗口（老板键）](../how-to/hide-window.md)。

## 窗口

| | 普通模式 | 悬浮模式 | 幽灵模式 |
|---|---|---|---|
| 层级 | 普通窗口，会被其他应用的窗口挡住 | 置顶，浮在其他应用的窗口上面 | 置顶，浮在其他应用的窗口上面 |
| 透明度 | 不透明 | 「设置 › 窗口模式 › 悬浮模式 › 透明度」设定的值，默认 80%；隐藏窗口时完全看不见 | 「设置 › 窗口模式 › 幽灵模式 › 透明度」设定的值，默认 20%；隐藏窗口时完全看不见 |
| 鼠标点击 | 正常点击网页 | 正常点击网页；隐藏窗口时点击会穿过窗口 | 点击会穿过窗口，落到下面的应用上 |
| 焦点 | 可以成为前台窗口，接收键盘输入 | 进入时成为前台窗口，之后跟普通窗口一样接收键盘输入；隐藏窗口时焦点交还给你之前在用的应用，窗口回来时不抢焦点，隐藏中从幽灵模式切过来也不抢 | 从不成为前台窗口；进入时如果 Mochi 在前台，焦点交还给你之前在用的应用 |
| 工具栏 | 显示交通灯按钮、地址栏和工具栏按钮 | 全部隐藏，只剩网页内容 | 全部隐藏，只剩网页内容 |
| 拖动、调整大小 | 可以，拖到屏幕边缘会吸附（可在「设置 › 通用 › 窗口 › 拖动时吸附屏幕边缘」关掉） | 可以拖窗口边缘调整大小；移动窗口要先回到普通模式 | 不行 |
| 刷新、停止、缩放、返回、前进 | 可以，用工具栏或「显示」「历史记录」菜单 | 可以，用「显示」「历史记录」菜单或快捷键 | 不行，这些菜单项是灰的 |
| 打开位置、添加书签 | 可以（「文件 › 打开位置…」「书签 › 添加书签…」） | 不行，这些菜单项是灰的（没有地址栏） | 不行，这些菜单项是灰的 |
| 关闭窗口 | ⌘W（Command + W）、红色按钮或「文件 › 关闭窗口」 | ⌘W 或「文件 › 关闭窗口」 | 不行，先退出幽灵模式 |

进入和退出悬浮模式时，网页在屏幕上的位置和大小不变：窗口只是收起或放回顶部的工具栏。

## 网页发起的请求

悬浮模式下，网页发起的请求跟普通模式一样处理。幽灵模式下，网页发起的需要你回应的请求都会被直接处理掉，不弹出任何东西，也不退出幽灵模式。悬浮模式下隐藏窗口时，按下表「幽灵模式」那一列处理：没人看得见的窗口上不该弹出任何东西。

| | 普通模式、悬浮模式 | 幽灵模式 |
|---|---|---|
| 对话框（提示、确认、输入） | 在窗口上弹出，等你回应 | 不弹出：提示自动关掉，确认和输入一律按取消处理 |
| 选择要上传的文件 | 弹出选择文件的窗口 | 不弹出，按取消处理 |
| 摄像头、麦克风 | 按「设置 › 网站 › 摄像头」「设置 › 网站 › 麦克风」的设置询问、允许或拒绝 | 直接拒绝，不询问；在设置里允许过的网站也一样 |
| 下载 | 存到「设置 › 通用 › 下载 › 文件下载位置」设定的位置；设成「每次询问」时弹出窗口让你选存储位置 | 不询问：设成「每次询问」时存到「下载」文件夹，其他设置照常 |
| 存不进「下载」文件夹时 | 弹出「无法存到下载文件夹」，让你去系统设置授权或换个位置 | 不弹出提示，这次下载不成功 |
| 登录小窗 | 打开 | 不打开 |
| 网页未经点击自行弹出的窗口 | 按「设置 › 网站 › 通用 › 弹出式窗口」的设置允许或阻止，默认阻止 | 不打开 |

登录小窗是独立的普通窗口，不跟着进入幽灵模式。进入幽灵模式前已经打开的登录小窗可以照常操作，它请求摄像头、麦克风时也照常询问。

## 按键

| | 普通模式 | 悬浮模式 | 幽灵模式 |
|---|---|---|---|
| 切换悬浮模式（默认 ⌥F） | 有效，进入悬浮模式 | 有效，回到普通模式（隐藏窗口时也有效） | 有效，直接进入悬浮模式（隐藏窗口时仍保持隐藏） |
| 切换幽灵模式（默认 ⌥G） | 有效，进入幽灵模式 | 有效，直接进入幽灵模式（隐藏窗口时仍保持隐藏） | 有效，回到普通模式（隐藏窗口时也有效） |
| 隐藏窗口（默认 ⌥H） | 没有作用，托盘里的「隐藏窗口」是灰的 | 有效，隐藏或恢复窗口 | 有效，隐藏或恢复窗口 |
| [视频控制](../how-to/video-control.md) | 没有作用 | 没有作用，隐藏窗口时也没有 | 有效，隐藏窗口时也有效 |
| [热键传递](../how-to/hotkey-forwarding.md) | 没有作用 | 没有作用，隐藏窗口时也没有 | 有效，隐藏窗口时也有效 |
| 菜单快捷键（⌘R、⌘L 这类） | Mochi 在前台时有效 | Mochi 在前台时有效，⌘L 和 ⌘D 除外 | 对 Mochi 窗口没有作用 |

每个按键的默认值和有效时机，见[快捷键与热键](shortcuts.md)。

## 打开网页与历史记录

| | 普通模式、悬浮模式 | 幽灵模式 |
|---|---|---|
| 从历史记录或书签打开网页 | 在窗口里打开，留在原来的模式里 | 在窗口里打开，并且留在幽灵模式里；隐藏窗口时也照样跳转，窗口仍然看不见 |
| 历史记录 | 记下访问 | 同样记下访问 |

窗口关着的时候从历史记录或书签打开网页，Mochi 会重新打开窗口并直接加载这个网页，窗口处于普通模式。

## 关闭与重新打开

| | 普通模式 | 悬浮模式 | 幽灵模式 |
|---|---|---|---|
| 关掉窗口再打开 | 回到普通模式 | 回到普通模式 | 不能直接关闭；退出幽灵模式再关，重新打开后是普通模式 |
| 退出 Mochi 再打开 | 回到普通模式 | 回到普通模式 | 也回到普通模式，不会接着上次的幽灵模式 |
| 点托盘或 Dock 里的「打开窗口」 | 把窗口带到前面 | 回到普通模式 | 回到普通模式 |

为什么这样设计，见[幽灵模式为什么这样设计](../explanation/ghost-mode-design.md)。
