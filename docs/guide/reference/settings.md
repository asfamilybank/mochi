# 设置项一览

按 ⌘,（Command + 逗号），或者选择菜单栏的「Mochi › 设置…」，就能打开设置。设置窗口分成 6 个面板，本页按面板分节，每一项写清楚作用、可选项、默认值和生效时机。

设置改了马上生效，不用重新打开 Mochi。例外的几项会在各自的条目里注明：脚本在下次加载页面时生效，自动播放在下次打开窗口时生效。

## 幽灵模式

### 外观

**目标透明度**

- **作用**：幽灵模式下窗口的透明程度。数字越小越透明，0% 时完全看不见。普通模式下窗口总是不透明，不受这一项影响。
- **可选项**：拖动滑块，在 0% 到 100% 之间调整，滑块右边显示当前的百分比。
- **默认值**：20%。
- **生效时机**：松开滑块时生效。正处于幽灵模式时，窗口马上变成新的透明度。

本面板底部的「恢复默认热键」不会改动透明度。

相关页面：[用幽灵模式让网页浮在最上层](../how-to/ghost-mode.md#调整透明度)。

### 全局热键

在任何应用里按下都有效，并会占用这个组合：Mochi 运行期间，其他应用收不到它。

**切换幽灵模式**

- **作用**：进入或退出幽灵模式。窗口关着时没有作用。
- **可选项**：点录制框，录一个组合键。至少要带 ⌃（Control）、⌥（Option）、⌘（Command）之一，只有 F1 到 F20 可以只带 ⇧（Shift）。也可以点录制框右边的 ⓧ 清除，不设热键。
- **默认值**：⌥G。
- **生效时机**：录下就生效，旧的组合马上还给其他应用。

**隐藏窗口**

- **作用**：幽灵模式下让窗口完全看不见，再按一次恢复，相当于老板键。普通模式下没有作用。
- **可选项**：同「切换幽灵模式」。
- **默认值**：⌥H。
- **生效时机**：录下就生效。

录下的组合不能用时（比如「已被其他应用占用」），这一行会用红字说明原因，原来的热键保持不变。各种提示的意思，见[修改全局热键](../how-to/global-hotkeys.md#提示是什么意思)。

**恢复默认热键**

在本面板最下面。把两个全局热键、视频控制的三个按键和后退/前进步长全部恢复成默认值，不删除热键传递的映射，也不改动透明度。所有这些都已经是默认值时，按钮是灰的。某个默认组合被占用时会提示「部分默认热键无法恢复」，见[修改全局热键](../how-to/global-hotkeys.md#恢复默认热键)。

相关页面：[修改全局热键](../how-to/global-hotkeys.md)。

### 视频控制

在幽灵模式下生效，窗口隐藏时也生效。按键照常传给你正在用的应用，不会被占用。

**播放/暂停、后退、前进**

- **作用**：播放/暂停、后退、前进页面里的视频。页面上有好几个视频时，选正在播放的，其次是最近播放过的，再其次是看得见的部分最大的。
- **可选项**：每一项先在下拉菜单里选触发方式，再录按键：
  - 「轻按」：单独按一下一颗修饰键，左右两侧算不同的键；
  - 「连按两次」：快速轻按同一颗修饰键两次；
  - 「组合键」：至少带 ⌃、⌥、⌘ 之一，只有 F1 到 F20 可以只带 ⇧；
  - 点录制框右边的 ⓧ 清除，不设按键。
- **默认值**：播放/暂停是轻按右 ⌥（右侧的 Option 键），后退是连按两次右 ⌘（右侧的 Command 键），前进是连按两次右 ⌥。
- **生效时机**：录下就生效。只选了触发方式、没录到键时，原来的按键不变。

**后退/前进步长**

- **作用**：按一次后退或前进跳过的秒数。
- **可选项**：1 到 60 秒，点上下箭头调整。
- **默认值**：5 秒。
- **生效时机**：马上生效。

**需要辅助功能权限**

只在视频控制里有不带 ⌃ 也不带 ⌘ 的组合键（比如 ⌥P）、而 Mochi 又没有「系统设置 › 隐私与安全性 › 辅助功能」权限时，才出现在本面板顶部。系统还没问过时，旁边的按钮是「请求权限」，问过之后是「打开系统设置」。获得权限后提示消失。怎么处理，见[故障排除](../how-to/troubleshooting.md#幽灵模式下视频控制的组合键如-p没反应)。

相关页面：[不切换应用就能控制视频](../how-to/video-control.md)。

### 热键传递

在幽灵模式下按触发键，Mochi 就向网页发送对应的按键，窗口隐藏时也生效。

**映射表**

- **作用**：列出已经添加的映射，每行左边是触发键，箭头右边是发给网页的按键。触发键是组合键的映射旁边有一个锁形图标，表示这个组合会被占用，其他应用里按不出来。点一行右边的垃圾桶按钮（「删除映射」）删除这条映射。映射不能直接修改，要改就删掉再重新添加。
- **默认值**：没有映射。
- **生效时机**：删除后马上生效，被占用的组合马上还给其他应用。

**添加映射**

- **作用**：在分组最下面那一行新建一条映射。
- **可选项**：触发方式（「组合键」「轻按」「连按两次」，默认「组合键」）、触发键、页面按键。页面按键可以是任意键，不必带修饰键，但不能是单独的 Esc、⌫ 或 ⌦。两个键都录好后，「添加映射」才能点。
- **生效时机**：点「添加映射」后马上生效。添加不成功时，这一行下面会用红字说明原因，见[把热键变成网页按键](../how-to/hotkey-forwarding.md#提示是什么意思)。

相关页面：[把热键变成网页按键](../how-to/hotkey-forwarding.md)。
