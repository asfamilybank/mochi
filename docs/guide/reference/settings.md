# 设置项一览

按 ⌘,（Command + 逗号），或者选择菜单栏的「Mochi › 设置…」，就能打开设置。设置窗口分成 7 个面板，本页按面板分节，每一项写清楚作用、可选项、默认值和生效时机。

设置改了马上生效，不用重新打开 Mochi。例外的几项会在各自的条目里注明：「启动时」和自动播放在下次打开窗口时生效，脚本在下次加载页面时生效，HTTP 警告从下一次打开网页起生效。

## 通用

![「设置 › 通用」面板](../images/settings-general.png)

### 启动 URL

**启动时**

- **作用**：窗口每次打开时先显示什么。“每次打开”指启动 Mochi，以及关闭窗口后重新打开它。
- **可选项**：
  - 「继续上次访问页面」：打开你最后一次自己打开的网址，也就是在地址栏里输入的，或者从历史记录、书签打开的。在网页里点链接跳过去的页面不算。从来没打开过网页时，显示空页面。
  - 「使用空页面」：显示空页面，上面有当前生效的热键速览。
  - 「指定网址」：每次都打开「输入网址」框里的网址。要输入完整的网址（以 `https://` 或 `http://` 开头）并按 Return（回车）才会保存。
- **默认值**：「继续上次访问页面」。
- **生效时机**：下次打开窗口时。不影响正在显示的网页。

相关页面：[打开网页与设置启动页](../how-to/open-pages.md#设置每次打开时先看到什么)。

### 搜索

**搜索引擎**

- **作用**：在地址栏里输入的内容不是网址时，用哪个搜索引擎搜索。
- **可选项**：Google、Bing、DuckDuckGo、百度。
- **默认值**：Google。
- **生效时机**：马上生效，下一次搜索就用新的。

### 下载

**文件下载位置**

- **作用**：网页上下载的文件存到哪里。
- **可选项**：
  - 「下载」：存到「下载」文件夹。第一次存进去时，系统会问你是否允许 Mochi 访问这个文件夹。
  - 「每次询问」：每次下载时弹出存储窗口，让你选位置和文件名。幽灵模式下不弹出，直接存到「下载」文件夹。
  - 「其他…」：选一个文件夹，以后都存到那里。选过之后，这个文件夹的名字会出现在菜单里「其他…」的上面。文件夹后来被删除或不能写入时，改存到「下载」文件夹。
- **默认值**：「下载」。
- **生效时机**：马上生效，从下一次下载起按新位置存。

「下载」文件夹存不进去时，这一栏下面会显示「上次没能存到「下载」文件夹：需要在系统设置里允许 Mochi 访问」和「打开系统设置」按钮。这条提示只在下载位置是「下载」时显示，之后成功存进一个文件就会消失。

相关页面：[下载文件](../how-to/downloads.md)。

### 窗口

**拖动时吸附屏幕边缘**

- **作用**：在普通模式下拖动窗口时，窗口靠近屏幕边缘或角落会自动贴过去，接着往反方向拖就能脱开。
- **可选项**：勾选（打开）/ 不勾选（关闭）。
- **默认值**：打开。
- **生效时机**：马上生效。

相关页面：[摆放和关闭窗口](../how-to/window-placement.md#吸附屏幕边缘)。

## 窗口模式

![「设置 › 窗口模式」面板](../images/settings-ghost-mode.png)

### 悬浮模式

**透明度**

- **作用**：悬浮模式下窗口的透明程度。数字越小越透明。跟幽灵模式的透明度分开设置。
- **可选项**：拖动滑块，在 10% 到 100% 之间调整，滑块右边显示当前的百分比。悬浮模式的窗口仍然接收点击和键盘输入，所以不能调到完全看不见。
- **默认值**：80%。
- **生效时机**：松开滑块时生效。正处于悬浮模式时，窗口马上变成新的透明度。

相关页面：[用悬浮模式边看边用网页](../how-to/float-mode.md#调整透明度)。

### 幽灵模式

**透明度**

- **作用**：幽灵模式下窗口的透明程度。数字越小越透明，0% 时完全看不见。普通模式下窗口总是不透明，不受这一项影响。
- **可选项**：拖动滑块，在 0% 到 100% 之间调整，滑块右边显示当前的百分比。
- **默认值**：20%。
- **生效时机**：松开滑块时生效。正处于幽灵模式时，窗口马上变成新的透明度。

相关页面：[用幽灵模式让网页浮在最上层](../how-to/ghost-mode.md#调整透明度)。

## 热键

### 全局热键

在任何应用里按下都有效，并会占用这个组合：Mochi 运行期间，其他应用收不到它。

**切换悬浮模式**

- **作用**：进入或退出悬浮模式；在幽灵模式下按，直接进入悬浮模式。窗口关着时没有作用。
- **可选项**：同「切换幽灵模式」。
- **默认值**：⌥F。
- **生效时机**：录下就生效。

**切换幽灵模式**

- **作用**：进入或退出幽灵模式；在悬浮模式下按，直接进入幽灵模式。窗口关着时没有作用。
- **可选项**：点录制框，录一个组合键。至少要带 ⌃（Control）、⌥（Option）、⌘（Command）之一，只有 F1 到 F20 可以只带 ⇧（Shift）。也可以点录制框右边的 ⓧ 清除，不设热键。
- **默认值**：⌥G。
- **生效时机**：录下就生效，旧的组合马上还给其他应用。

**隐藏窗口**

- **作用**：悬浮模式或幽灵模式下让窗口完全看不见，再按一次恢复，相当于老板键。普通模式下没有作用。
- **可选项**：同「切换幽灵模式」。
- **默认值**：⌥H。
- **生效时机**：录下就生效。

录下的组合不能用时（比如「已被其他应用占用」），这一行会用红字说明原因，原来的热键保持不变。各种提示的意思，见[修改全局热键](../how-to/global-hotkeys.md#提示是什么意思)。

**恢复默认热键**

在本面板最下面。把三个全局热键、视频控制的三个按键和后退/前进步长全部恢复成默认值，不删除热键传递的映射，也不改动透明度。所有这些都已经是默认值时，按钮是灰的。某个默认组合被占用时会提示「部分默认热键无法恢复」，见[修改全局热键](../how-to/global-hotkeys.md#恢复默认热键)。

相关页面：[修改全局热键](../how-to/global-hotkeys.md)。

### 视频控制

在幽灵模式下生效，窗口隐藏时也生效。按键照常传给你正在用的应用，不会被占用。

**播放/暂停、后退、前进**

- **作用**：播放/暂停、后退、前进页面里的视频。页面上有好几个视频时，选正在播放的，其次是最近播放过的，再其次是看得见的部分最大的。
- **可选项**：每一项先在下拉菜单里选触发方式，再录按键：
  - 「轻按」：单独按一下一颗修饰键，左右两侧算不同的键；
  - 「连按两次」：快速轻按同一颗修饰键两次；
  - 「组合键」：至少带 ⌃、⌥、⌘ 之一，只有 F1 到 F20 可以只带 ⇧；
  - 点录制框右边的 ⓧ 清除，不设按键。
- **默认值**：播放/暂停是轻按右 ⌥（右侧的 Option 键），后退是连按两次右 ⌘（右侧的 Command 键），前进是连按两次右 ⌥。
- **生效时机**：录下就生效。只选了触发方式、没录到键时，原来的按键不变。

**后退/前进步长**

- **作用**：按一次后退或前进跳过的秒数。
- **可选项**：1 到 60 秒，点上下箭头调整。
- **默认值**：5 秒。
- **生效时机**：马上生效。

**需要辅助功能权限**

只在视频控制里有不带 ⌃ 也不带 ⌘ 的组合键（比如 ⌥P）、而 Mochi 又没有「系统设置 › 隐私与安全性 › 辅助功能」权限时，才出现在本面板顶部。系统还没问过时，旁边的按钮是「请求权限」，问过之后是「打开系统设置」。获得权限后提示消失。怎么处理，见[故障排除](../how-to/troubleshooting.md#幽灵模式下视频控制的组合键如-p没反应)。

相关页面：[不切换应用就能控制视频](../how-to/video-control.md)。

### 热键传递

在幽灵模式下按触发键，Mochi 就向网页发送对应的按键，窗口隐藏时也生效。

**映射表**

- **作用**：列出已经添加的映射，每行左边是触发键，箭头右边是发给网页的按键。触发键是组合键的映射旁边有一个锁形图标，表示这个组合会被占用，其他应用里按不出来。点一行右边的垃圾桶按钮（「删除映射」）删除这条映射。映射不能直接修改，要改就删掉再重新添加。
- **默认值**：没有映射。
- **生效时机**：删除后马上生效，被占用的组合马上还给其他应用。

**添加映射**

- **作用**：在分组最下面那一行新建一条映射。
- **可选项**：触发方式（「组合键」「轻按」「连按两次」，默认「组合键」）、触发键、页面按键。页面按键可以是任意键，不必带修饰键，但不能是单独的 Esc、⌫ 或 ⌦。两个键都录好后，「添加映射」才能点。
- **生效时机**：点「添加映射」后马上生效。添加不成功时，这一行下面会用红字说明原因，见[把热键变成网页按键](../how-to/hotkey-forwarding.md#提示是什么意思)。

相关页面：[把热键变成网页按键](../how-to/hotkey-forwarding.md)。

## 网站

![「设置 › 网站」面板](../images/settings-websites.png)

面板左边是一个列表：「通用」「摄像头」「麦克风」，选中哪一项，右边就显示哪一项的设置。

### 通用

**自动播放**

- **作用**：网页打开时，能不能不等你点击就自己播放视频和声音。
- **可选项**：
  - 「允许全部自动播放」：网页想播就播。
  - 「停止有声媒体」：带声音的视频和音频要你点了才播放，静音的可以自己播放。
  - 「永不自动播放」：所有视频和音频都要你点了才播放。
- **默认值**：「允许全部自动播放」。这样重新打开 Mochi、回到上次看的视频网页时，视频能接着播。
- **生效时机**：**下次打开窗口时生效**，这是本页少数不马上生效的设置之一。想马上生效，点下面的「重新打开窗口」：窗口会关掉再重新打开，跟重新打开 Mochi 时一样，按「设置 › 通用」里「启动时」的设置加载页面。

**弹出式窗口**

- **作用**：网页没经过你点击、自己弹出来的窗口要不要打开。你点了登录按钮才打开的登录小窗不受这一项影响。
- **可选项**：「允许」「阻止」。选「允许」时，这类窗口会像登录小窗一样打开。
- **默认值**：「阻止」。
- **生效时机**：马上生效。
- 幽灵模式下，不管选哪一项，这类窗口和登录小窗都不会打开。

相关页面：[登录网站](../how-to/sign-in.md#弹出式窗口设置管的是什么)、[故障排除：打开网页就自动出声](../how-to/troubleshooting.md#打开网页就自动出声)。

### 摄像头

决定网站能不能使用摄像头，也就是「网页权限」。网站按发起请求的那个页面的主机名区分，`meet.google.com` 和 `calendar.google.com` 算两个网站。

**已配置的网站**

- **作用**：列出你单独设置过的网站，每个网站一行，右边是它的设置。你在网页的询问框里选「访问此网站时允许」或「不允许」后，网站就会出现在这里。
- **可选项**：每一行可以选「询问」「拒绝」或「允许」。选中一行或多行后点「移除」，或者按 ⌫（Delete），这些网站就回到「访问其他网站时」的设置。
- **默认值**：空列表。
- **生效时机**：马上生效，从网页下一次请求起按新设置处理。已经在用摄像头的网页会一直用到它重新加载页面为止。

**访问其他网站时**

- **作用**：列表里没有的网站要用摄像头时怎么办。
- **可选项**：「询问」：弹出询问框问你；「拒绝」：直接拒绝；「允许」：直接允许。
- **默认值**：「询问」。
- **生效时机**：马上生效，从网页下一次请求起按新设置处理。

**系统权限提示**

Mochi 还没获得 macOS 的摄像头权限时，面板顶部会显示一条提示：

| 提示 | 意思 | 按钮 |
|---|---|---|
| 「Mochi 还没有获得摄像头权限，网页暂时无法使用摄像头。」 | 系统还没问过 | 「请求权限」 |
| 「Mochi 的摄像头权限已被拒绝，网页无法使用摄像头。」 | 之前在系统的提示里选了不允许 | 「打开系统设置」 |
| 「摄像头权限受管理策略限制，网页无法使用摄像头。」 | 这台 Mac 由公司或学校管理，改不了 | 无 |

「访问其他网站时」和列表里所有网站都是「拒绝」时，网页过不了 Mochi 这一关，这条提示就不会出现。在系统设置里改了这项权限后，要退出并重新打开 Mochi 才会生效。

不管这里怎么设，幽灵模式下 Mochi 窗口里的网页要用摄像头时都会被直接拒绝；登录小窗照常按这里的设置处理。

相关页面：[让网页使用摄像头和麦克风](../how-to/camera-and-microphone.md)。

### 麦克风

跟[摄像头](#摄像头)一样，有「已配置的网站」「访问其他网站时」和系统权限提示三部分，选项、默认值和生效时机都相同，提示里的「摄像头」换成「麦克风」。摄像头和麦克风分开设置：一个网站可以允许用麦克风、不允许用摄像头。

网页同时要摄像头和麦克风时，两项设置不一样的话按更严格的那项处理：「拒绝」比「询问」严格，「询问」比「允许」严格。

相关页面：[让网页使用摄像头和麦克风](../how-to/camera-and-microphone.md)。

## 隐私与安全性

![「设置 › 隐私与安全性」面板](../images/settings-privacy.png)

### 历史记录

**「移除历史记录项目」**

- **作用**：历史记录留多久。超过这个期限的访问会自动移除。
- **可选项**：「一天后」「一周后」「两周后」「一个月后」「一年后」「手动」。选「手动」时 Mochi 不会自动删除任何记录。
- **默认值**：「一年后」。
- **生效时机**：马上生效。把期限改短，超出新期限的记录当场删掉；之后每次打开 Mochi、每次打开历史记录窗口时也会再清一次。

相关页面：[查找和管理历史记录](../how-to/history.md#设置保留期限)。

### 网站数据

这一组是两个按钮，不是设置项。点了只是打开对应的窗口，要在窗口里再点删除或清除的按钮，才会真的删掉数据：

- 「管理网站和数据…」：按网站查看并删除 Cookie、缓存等网站数据，或者重置网页权限。
- 「清除浏览数据…」：按时间范围清除历史记录、Cookie 和网站数据、缓存的图片和文件、网页权限例外。跟菜单栏的「历史记录 › 清除浏览数据…」是同一个对话框。

两者各清掉什么、会不会退出登录，见[清除浏览数据和网站数据](../how-to/clear-data.md)。

### 安全性

**「通过 HTTP 连接网站前接收警告」**

- **作用**：打开 `http://` 开头的网址时，先尝试用更安全的 HTTPS 连接；网站不支持 HTTPS 时，先显示「此连接不安全」警告页，你可以点「返回」，也可以点「继续」接着用 HTTP 打开。登录小窗也一样。本机地址（比如 `http://127.0.0.1`）不会出现警告页，会直接打开。
- **可选项**：勾选（打开）/ 不勾选（关闭）。
- **默认值**：关闭。
- **生效时机**：从下一次打开网页起生效。

## 脚本

这个面板里的三项都在**下次加载页面时**生效，面板顶部写着「脚本改动将在下次加载页面后生效」。想马上生效，点旁边的「刷新页面」。怎么写脚本和样式表、有什么风险，见[用脚本和样式表调整网页](../how-to/scripts.md)。

![「设置 › 脚本」面板](../images/settings-scripts.png)

### 官方内置适配脚本

**「通用视频对焦适配」**

- **作用**：网页加载完之后，把键盘焦点交给网页上的第一个视频，让热键传递发给网页的按键落到播放器上。
- **可选项**：勾选（打开）/ 不勾选（关闭）。
- **默认值**：打开。
- **生效时机**：下次加载页面时。

### 自定义脚本

- **作用**：你自己写的 JavaScript，每次网页加载完都在 Mochi 窗口的主网页里运行一次，对所有网站都运行。
- **可选项**：在框里填写任意 JavaScript，点「保存」存下来；清空后点「保存」就是删除。
- **默认值**：空，不运行任何脚本。
- **生效时机**：下次加载页面时。

### 自定义样式表

- **作用**：你自己写的 CSS，每次网页加载完都加到网页上，对所有网站都有效。
- **可选项**：在框里填写任意 CSS，点「保存样式表」存下来；清空后点「保存样式表」就是删除。
- **默认值**：空。
- **生效时机**：下次加载页面时。

## 高级

![「设置 › 高级」面板](../images/settings-advanced.png)

### 辅助功能

这一节的「辅助功能」管的是网页的字体大小，跟「系统设置 › 隐私与安全性 › 辅助功能」里的系统权限无关。视频控制需要的辅助功能权限，要到系统设置里给。

**「字体大小不得小于」**

- **作用**：网页上的文字不会小于你选的字号，太小的字会被放大到这个字号。Mochi 窗口和登录小窗都适用。
- **可选项**：先勾选，再在右边选字号：9、10、11、12、14、18、24。不勾选就是不限制。
- **默认值**：不勾选。第一次勾选时字号是 9。
- **生效时机**：马上生效。

### 开发

**「显示网页开发者功能」**

- **作用**：允许用网页检查器查看和调试 Mochi 里的网页，包括登录小窗。打开后，可以在网页上点右键，用检查元素打开网页检查器。
- **可选项**：勾选（打开）/ 不勾选（关闭）。
- **默认值**：关闭。
- **生效时机**：马上生效。
