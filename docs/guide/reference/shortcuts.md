# 快捷键与热键

本页列出 Mochi 的所有按键。按键写成符号：⌘ 是 Command，⌥ 是 Option，⇧ 是 Shift，⌃ 是 Control；「右 ⌥」指键盘右侧的 Option 键，「右 ⌘」指右侧的 Command 键。

Mochi 的按键分成四类，有效的时机各不相同：

| 类别 | 什么时候有效 | 会不会占用这个组合 |
|---|---|---|
| [全局热键](#全局热键) | 在任何应用里都有效 | 会：Mochi 运行期间，其他应用收不到这个组合 |
| [视频控制](#视频控制) | 只在幽灵模式下，窗口隐藏时也有效 | 不会：按键照常传给你正在用的应用 |
| [热键传递](#热键传递) | 只在幽灵模式下，窗口隐藏时也有效 | 触发键是组合键时会，轻按和连按两次不会 |
| [菜单快捷键](#菜单快捷键) | Mochi 在前台时 | 不会，只在 Mochi 里起作用 |

“占用”和“旁听”有什么区别，见[按键是怎么被 Mochi 听到的](../explanation/how-keys-are-heard.md)。

## 全局热键

| 功能 | 默认 | 什么时候有效 |
|---|---|---|
| 切换幽灵模式 | ⌥G | 窗口开着时，在任何应用里按都有效：普通模式下按是进入幽灵模式，幽灵模式下按是退出 |
| 隐藏窗口 | ⌥H | 只在幽灵模式下有效：按一次隐藏窗口，再按一次恢复。普通模式下没有作用 |

窗口关着的时候，这两个热键都没有作用。在[修改全局热键](../how-to/global-hotkeys.md)里可以换成别的组合键。

## 视频控制

| 功能 | 默认 |
|---|---|
| 播放/暂停 | 轻按右 ⌥ |
| 后退 | 连按两次右 ⌘，后退 5 秒 |
| 前进 | 连按两次右 ⌥，前进 5 秒 |

「轻按」是单独按一下修饰键再松开，「连按两次」是快速轻按同一颗修饰键两次。按键、触发方式和步长都可以改，见[不切换应用就能控制视频](../how-to/video-control.md)。

## 热键传递

默认没有任何映射。你添加的每条映射，都在幽灵模式下把触发键变成一次网页按键，见[把热键变成网页按键](../how-to/hotkey-forwarding.md)。

## 菜单快捷键

只在 Mochi 是前台应用时有效。幽灵模式下，作用于 Mochi 窗口的菜单项都是灰的，按快捷键也没有作用。

| 菜单 | 菜单项 | 快捷键 | 说明 |
|---|---|---|---|
| Mochi | 设置… | ⌘, | 打开设置窗口 |
| Mochi | 隐藏 Mochi | ⌘H | 系统的隐藏应用功能，跟「隐藏窗口」不是一回事 |
| Mochi | 隐藏其他 | ⌥⌘H | 隐藏其他应用 |
| Mochi | 退出 Mochi | ⌘Q | |
| 文件 | 打开位置… | ⌘L | 把 Mochi 窗口带到前面并跳到地址栏；窗口关着时会先打开它 |
| 文件 | 关闭窗口 | ⌘W | 关闭最前面的那个窗口，可能是 Mochi 窗口，也可能是设置、历史记录或书签窗口 |
| 编辑 | 撤销 | ⌘Z | |
| 编辑 | 重做 | ⇧⌘Z | |
| 编辑 | 剪切 | ⌘X | |
| 编辑 | 拷贝 | ⌘C | |
| 编辑 | 粘贴 | ⌘V | |
| 编辑 | 粘贴并匹配样式 | ⌥⇧⌘V | |
| 编辑 | 全选 | ⌘A | |
| 显示 | 停止 | ⌘. | 只在网页正在加载时可用 |
| 显示 | 重新载入页面 | ⌘R | |
| 显示 | 放大 | ⌘+ | |
| 显示 | 缩小 | ⌘- | |
| 显示 | 实际大小 | ⌘0 | |
| 历史记录 | 返回 | ⌘[ | |
| 历史记录 | 前进 | ⌘] | |
| 历史记录 | 显示全部历史记录 | ⌘Y | 打开历史记录窗口；它已经在最前面时，按一下就关掉 |

系统自动加进菜单的项目（比如「编辑」菜单里的听写、表情与符号，「窗口」菜单里的其他项目）不在表里，它们的快捷键直接显示在菜单里。

## 设置里录制按键时

在「设置 › 窗口模式」里点录制框开始录制后：

| 按键 | 作用 |
|---|---|
| Esc | 取消录制，保留原来的按键 |
| ⌫ 或 ⌦ | 清除这一项的按键 |

带修饰键时，Esc、⌫、⌦ 就跟其他键一样，可以被录下来。

## 不能设成热键的组合

下面这些是 Mochi 菜单里的快捷键，不能设成全局热键、视频控制的组合键或映射的触发键，录制时会提示「这是 Mochi 菜单里的快捷键」：

⌘,、⌘L、⌘R、⌘.、⌘+、⌘-、⌘0、⌘[、⌘]、⌘Y、⌘D、⌥⌘B、⌘H、⌥⌘H

此外，组合键至少要带 ⌃、⌥、⌘ 之一；只有 F1 到 F20 可以只带 ⇧。

## 空页面上的热键速览

空页面上的「热键」速览，列的是**当前生效**的按键：全局热键、视频控制的按键，以及打开设置的 ⌘,。你改过的按键显示新的组合，清除掉的不显示；只在幽灵模式下有效的几项后面写着「（幽灵模式下）」，连按两次的键旁边标着「×2」。热键传递的映射不在速览里。
