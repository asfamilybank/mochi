# 术语表

手册里用到的词，每个一句话解释。界面上出现过的词，写法跟界面一致。

## 窗口与模式

**窗口 / Mochi 窗口**：Mochi 用来显示网页的那一个窗口，一次只放一个网页，没有标签页，也不能同时开多个。参见[Mochi 是什么，不是什么](../explanation/what-is-mochi.md)、[摆放和关闭窗口](../how-to/window-placement.md)。

**普通模式**：Mochi 窗口平时的状态，跟一个普通的 macOS 窗口一样，有工具栏和地址栏，可以点击、输入，不会浮在其他窗口上面。参见[普通模式与幽灵模式对照](modes.md)。

**幽灵模式**：让网页浮在最上层又不碍事的状态：工具栏隐藏、窗口变透明、置顶、点击会穿过窗口、不抢走你正在用的应用，这几件事总是一起打开、一起关闭。参见[用幽灵模式让网页浮在最上层](../how-to/ghost-mode.md)、[幽灵模式为什么这样设计](../explanation/ghost-mode-design.md)。

**隐藏窗口**：相当于老板键，只在幽灵模式下可用，让窗口完全看不见，网页还在运行，视频和声音会暂停；再按一次热键窗口就回来，但视频不会自动继续播放。参见[一键隐藏窗口（老板键）](../how-to/hide-window.md)。

**吸附屏幕边缘**：在普通模式下拖动窗口靠近屏幕边缘或角落时，窗口会自动贴齐，继续往反方向拖就能脱开，可以在「设置 › 通用 › 窗口 › 拖动时吸附屏幕边缘」里关掉。参见[摆放和关闭窗口](../how-to/window-placement.md#吸附屏幕边缘)。

**鼠标穿透 / 点击会穿过窗口**：幽灵模式自带的效果，窗口不接收鼠标点击，点击直接落到下面的应用上，不能单独打开或关闭。参见[幽灵模式为什么这样设计](../explanation/ghost-mode-design.md#为什么幽灵模式里不能点网页)。

## 按键

**视频控制**：在幽灵模式下（包括窗口隐藏时）用按键暂停、播放、后退、前进网页里的视频，按键照常传给你正在用的应用，不会被 Mochi 占用。

**热键传递**：在幽灵模式下按你设定的触发键，Mochi 就向网页发送一个对应的按键，让你不切换到 Mochi 也能用网站自带的快捷键。

**映射**：热键传递里的一条设置，由一个触发键和要发给网页的按键组成，在「设置 › 幽灵模式 › 热键传递」里点「添加映射」新建。

**触发键**：按下后执行某个功能的键，有三种触发方式：「轻按」是单独按一下 ⌥（Option）、⌘（Command）这类修饰键（左右两侧算两个不同的键），「连按两次」是快速轻按同一个修饰键两次，「组合键」是按住修饰键再按另一个键。

## 网页与网站

**登录小窗**：网页为了让你登录（比如用微信或 Google 账号登录）而临时打开的小窗口，跟 Mochi 窗口共用登录状态，登录完会自己关掉，跟「设置 › 网站 › 通用」里的「弹出式窗口」管的不是一回事。

**官方内置适配脚本**：Mochi 自带、随版本更新的脚本，让一些网站在 Mochi 里更好用，可以在「设置 › 脚本」里逐个关掉。参见[用脚本和样式表调整网页](../how-to/scripts.md#官方内置适配脚本)。

**自定义脚本**：你自己写的一段 JavaScript，Mochi 每次加载页面时把它放进网页里运行，它能读到你在网页上的一切，只粘贴你看得懂的代码。参见[用脚本和样式表调整网页](../how-to/scripts.md#写自定义脚本)。

**自定义样式表**：你自己写的一段 CSS，Mochi 每次加载页面时把它加到网页上，用来改网页的样子。参见[用脚本和样式表调整网页](../how-to/scripts.md#写自定义样式表)。

**网页权限**：Mochi 允许哪些网站使用摄像头和麦克风，按网站分别记下，在「设置 › 网站」里管理。

**系统权限**：macOS 允许 Mochi 这个应用做的事，比如辅助功能、摄像头、麦克风、文件和文件夹，在「系统设置 › 隐私与安全性」里管理，卸载 Mochi 也不会自动清掉。每项权限什么时候需要，见[Mochi 存放的数据与系统权限](data-and-permissions.md#系统权限)。

**网站数据**：网站存在 Mochi 里的 Cookie、缓存等内容，登录状态就在里面，删掉某个网站的网站数据就会退出这个网站的登录。存在电脑上的哪里，见[Mochi 存放的数据与系统权限](data-and-permissions.md#数据存在哪里)。

## 历史记录与书签

**历史记录**：Mochi 记下的你在窗口里访问过的网页，幽灵模式下的访问也会记，登录小窗和空页面不记。

**书签**：你自己存下来的网页，只有你自己能删，清除历史记录或网站数据都不会动它。

**地址栏建议**：在地址栏输入时给出的候选网址，包括直接补进输入框的部分和下拉列表，只来自本机的书签和历史记录，你输入的内容不会发给搜索引擎。参见[打开网页与设置启动页](../how-to/open-pages.md#地址栏建议从哪里来)。
