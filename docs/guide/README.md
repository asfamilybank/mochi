# Mochi 用户手册

本手册对照 Mochi 0.3 编写。

还没装 Mochi？安装和第一次打开时的放行步骤请看 [README 的「安装」一节](../../README.md#安装)。

遇到问题，先看 [故障排除](how-to/troubleshooting.md)：按症状查原因和做法。

手册按用途分成四类。还没写好的页面暂时没有链接。

## 教程

跟着做一遍，学会核心用法。

- 上手：把视频放在桌面角落，边工作边看——第一次打开 Mochi 后，十几分钟走完一遍核心用法，弄清它跟普通浏览器的区别。

## 操作指南

已经知道要做什么，查怎么做。

- [打开网页与设置启动页](how-to/open-pages.md)——输入网址或直接搜索，并决定每次打开 Mochi 时先看到什么。
- [摆放和关闭窗口](how-to/window-placement.md)——把窗口放到想要的位置，弄清关闭和重新打开会发生什么。
- [用幽灵模式让网页浮在最上层](how-to/ghost-mode.md)——让网页一直浮在最上层，又不挡住你在别的应用里的操作。
- [一键隐藏窗口（老板键）](how-to/hide-window.md)——有人走过来时，一下就让窗口消失。
- 不切换应用就能控制视频——在别的应用里打字、开会时，也能暂停、快进、后退视频。
- 把热键变成网页按键——不切换到 Mochi，也能用网站自带的快捷键，比如开关弹幕、全屏、下一集。
- 修改全局热键——把切换幽灵模式和隐藏窗口的热键换成顺手、不冲突的键。
- [登录网站](how-to/sign-in.md)——在 Mochi 里登录视频网站或其他账号，并知道怎么退出登录。
- [让网页使用摄像头和麦克风](how-to/camera-and-microphone.md)——在 Mochi 里开视频会议，或者收回某个网站的摄像头授权。
- [下载文件](how-to/downloads.md)——知道下载的文件去了哪里，并能改下载位置。
- 查找和管理历史记录——找回看过的网页，删掉不想留的记录。
- 使用书签——存下常看的网页，下次一步打开。
- 清除浏览数据和网站数据——清理痕迹、退出某个网站的登录，或者解决某个网站一直不正常的问题。
- [用脚本和样式表调整网页](how-to/scripts.md)——给常用的网站改改样式，或者加一点自动化，适合会写一点网页代码的人。
- [升级 Mochi](how-to/upgrade.md)——换到新版本，设置和数据不丢，功能照常可用。
- [卸载 Mochi](how-to/uninstall.md)——干净地移除 Mochi。
- 故障排除——带着一个症状进来，找到原因和做法。

## 原理说明

想知道 Mochi 为什么这样设计时读这里。

- [Mochi 是什么，不是什么](explanation/what-is-mochi.md)——弄清 Mochi 的定位，不拿它当 Safari 用，也就不会为少了某个功能感到困惑。
- [幽灵模式为什么这样设计](explanation/ghost-mode-design.md)——幽灵模式里那些限制背后的道理。
- 按键是怎么被 Mochi 听到的——为什么有的键会被占用、有的不会，以及为什么有的键需要权限。
- Mochi 记下什么、不发给谁——放心使用，并分清网页权限、系统权限和网站数据。
- [为什么第一次打开会被拦下](explanation/unsigned-app.md)——被系统拦下、升级后权限失效，为什么是预期内的，而且是安全的。
