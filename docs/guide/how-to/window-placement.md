# 摆放和关闭窗口

这一页讲怎么把 Mochi 窗口放到想要的位置，以及关闭窗口、重新打开时会发生什么。

## 移动和调整大小

在普通模式下，Mochi 窗口跟其他 macOS 窗口一样：

- **移动**：按住窗口顶部工具栏的空白处拖动。
- **调整大小**：拖动窗口的边缘或角落。

窗口不能窄于一定宽度，免得工具栏挤不下。窗口比较窄时，工具栏右端的「进入幽灵模式」按钮会先隐藏起来，这时可以用 ⌥G（Option + G）或者菜单栏里 Mochi 图标的菜单进入幽灵模式。

幽灵模式下点击会穿过窗口，所以没法拖动它，也没法调整大小。要挪窗口，先按 ⌥G 退出幽灵模式，摆好后再进入。

## 吸附屏幕边缘

拖动窗口时，窗口的边缘靠近屏幕边缘或角落，就会自动贴过去。这里的屏幕边缘不包括菜单栏和程序坞（Dock）占的地方，窗口会贴在它们旁边，不会压到它们上面。

- **脱开**：接着往反方向拖，离开一小段距离后窗口就不再贴着。
- **调整大小时不吸附**：只有拖动整个窗口时才会贴齐，拖边缘改大小时不会。
- **关掉吸附**：在「设置 › 通用 › 窗口 › 拖动时吸附屏幕边缘」里取消勾选。默认是打开的，改完马上生效。

macOS 自己也会在窗口推到屏幕边缘时挡一下，所有窗口都这样。这跟 Mochi 的吸附是两回事，关掉吸附之后仍然会有。

## 用系统的平铺

macOS 自带的窗口平铺对 Mochi 窗口同样有效，比如把窗口拖到屏幕边缘变成半屏，或者用「窗口」菜单里系统提供的移动与调整大小选项。

## 拔掉外接显示器之后

Mochi 会记住窗口的位置、大小和网页的缩放比例，在关闭窗口或退出 Mochi 时保存下来，下次打开时放回原处。

如果保存的位置已经不在任何一块显示器上，比如窗口原来放在已经拔掉的外接显示器上，下次打开时窗口会回到主显示器的正中间，恢复默认大小。

Mochi 正在运行时拔掉显示器，macOS 一般会把窗口挪到还连着的显示器上。

## 关闭窗口

在普通模式下，用下面任意一种方式关闭窗口：

- 按 ⌘W（Command + W）。
- 选择菜单栏的「文件 › 关闭窗口」。
- 点窗口左上角的红色按钮。

幽灵模式下窗口没有红色按钮，也收不到按键，所以没法关闭。要关闭，先按 ⌥G 退出幽灵模式。

⌘W 关闭的是最前面的那个 Mochi 窗口。设置、历史记录或书签窗口在最前面时，⌘W 关的是那个窗口，不是网页窗口。

### 关闭是真的关闭

关闭窗口后：

- 网页停止运行，视频和声音都会停下。
- 网页打开的登录小窗也会一起关掉。
- 后退、前进的记录清空。
- 「切换悬浮模式」「切换幽灵模式」和「隐藏窗口」这三个热键不再起作用，直到你重新打开窗口。

Mochi 本身没有退出，仍然在菜单栏和程序坞里，随时可以重新打开窗口。

### 关闭和隐藏窗口的区别

如果你只是想让窗口暂时看不见，用「隐藏窗口」，它相当于老板键，见[一键隐藏窗口（老板键）](hide-window.md)。

| | 隐藏窗口 | 关闭窗口 |
|---|---|---|
| 在什么模式下用 | 只在幽灵模式下 | 只在普通模式下 |
| 怎么做 | 按 ⌥H，或点菜单栏里 Mochi 图标菜单的「隐藏窗口」 | 按 ⌘W，或点红色按钮 |
| 窗口 | 还在原处，只是完全看不见 | 不存在了 |
| 网页 | 继续运行，视频和声音会暂停 | 停止运行 |
| 怎么回来 | 再按一次 ⌥H | 重新打开窗口，网页从头加载 |

## 重新打开窗口

窗口关闭后，用下面任意一种方式重新打开：

- 点菜单栏里的 Mochi 图标，选「打开窗口」。
- 点程序坞里的 Mochi 图标。
- 按 ⌘L，或者选择菜单栏的「文件 › 打开位置…」。窗口打开后，地址栏会被选中，可以直接输入网址。
- 从「历史记录」或「书签」菜单里选一个网页，窗口会重新打开并直接加载它。

重新打开窗口跟重新启动 Mochi 一样：

- 先显示什么，按「设置 › 通用 › 启动 URL › 启动时」来定，见[设置每次打开时先看到什么](open-pages.md#设置每次打开时先看到什么)。
- 网页从头加载，不会接着关闭前播放到的位置。
- 窗口回到普通模式。
- 位置、大小和缩放比例跟关闭前一样。

窗口没有关闭时，「打开窗口」和点程序坞图标会把窗口带到最前面；如果窗口正处于幽灵模式，会先退出幽灵模式。

## 退出 Mochi

想让 Mochi 完全停下来，按 ⌘Q，或者选择菜单栏的「Mochi › 退出 Mochi」，也可以点菜单栏里的 Mochi 图标，选「退出」。
