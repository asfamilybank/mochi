# 一键隐藏窗口（老板键）

「隐藏窗口」相当于老板键：有人走过来时按一下，Mochi 窗口立刻完全看不见；再按一下，它就回到原来的位置。

## 隐藏和恢复

1. 先让窗口处于[悬浮模式](float-mode.md)或[幽灵模式](ghost-mode.md)。
2. 按 ⌥H（Option + H），或者点菜单栏里的 Mochi 图标（托盘图标），选「隐藏窗口」。窗口立刻完全看不见；如果 Mochi 在前台，焦点回到你之前在用的应用。
3. 想让它回来，再按一次 ⌥H，或者再选一次「隐藏窗口」（隐藏期间它前面有一个勾）。窗口回到隐藏前的样子，仍然在原来的模式里。窗口回来时不会把焦点抢回 Mochi，你手上的应用照常接收键盘输入；悬浮模式下要操作网页，点一下它就行。

窗口隐藏期间一直保持隐藏，不会自己回来。在悬浮模式和幽灵模式之间切换（⌥F、⌥G），窗口也仍然隐藏着，只是换了模式。回到普通模式会让它重新显示出来：在悬浮模式下按 ⌥F（Option + F）、在幽灵模式下按 ⌥G（Option + G），或者在托盘里选「打开窗口」。

隐藏期间窗口不接收点击，网页发起的请求（对话框、摄像头、下载、登录小窗）都直接处理掉，不弹出任何东西，悬浮模式下也一样。见[三种模式对照](../reference/modes.md#网页发起的请求)。

## 连程序坞和 ⌘Tab 里的图标一起藏起来

默认情况下，窗口隐藏时 Mochi 的图标还留在程序坞（Dock）和 ⌘Tab（Command + Tab）的应用切换器里。想让它们也一起消失：

1. 按 ⌘,（Command + 逗号），或者点菜单栏里的 Mochi 图标，选「设置…」。
2. 在「设置 › 窗口模式 › 隐藏」里勾选「隐藏时也从 Dock 和 ⌘Tab 中移除」。

之后每次隐藏窗口，程序坞和 ⌘Tab 里的 Mochi 都会一起消失；窗口回来、回到普通模式，或者取消勾选时，它们会重新出现。两处只能一起移除，没法只藏其中一处。

- 菜单栏里的 Mochi 图标一直保留。图标不在程序坞里时，用它或者 ⌥H 找回窗口。
- 图标消失和出现时，程序坞会播放系统自带的动画。
- 图标最多每秒变化一次：连续快速按 ⌥H 时，窗口每一下都立刻响应，程序坞里的图标可能晚一秒才跟上。

## 为什么普通模式下没有作用

隐藏窗口属于悬浮模式和幽灵模式，在普通模式下没有作用：托盘里的「隐藏窗口」是灰的，按 ⌥H 也没有反应。空页面的热键速览里，它也写成「隐藏窗口（悬浮或幽灵模式下）」。

普通模式下的窗口就是一个普通的 macOS 窗口，想把它收起来，用系统自带的办法就行：「窗口 › 最小化」（⌘M，即 Command + M），或者「Mochi › 隐藏 Mochi」（⌘H）。注意「隐藏 Mochi」是系统给每个应用都配的隐藏应用功能，跟这里的「隐藏窗口」不是一回事。

为什么这样设计，见[幽灵模式为什么这样设计](../explanation/ghost-mode-design.md#为什么隐藏窗口在普通模式下没有作用)。

## 隐藏时网页会怎样

- **网页还在运行**：窗口只是看不见，没有关掉。网页的登录状态、你看到的位置都还在。
- **视频和声音会暂停**：隐藏的那一刻，页面上所有正在播放的视频和音频都会暂停，包括嵌在网页里、来自其他网站的播放器。
- **幽灵模式下，视频控制和热键传递照常可用**：隐藏期间按视频控制的「播放/暂停」键，视频会在看不见的窗口里接着播放，适合只想听声音的时候。这两项只在幽灵模式下有效，悬浮模式下隐藏时用不了。

少数网页的声音不是由网页里的播放器发出的（比如网页游戏的音效），隐藏时可能不会停。

## 恢复后视频不会自动继续播放

窗口回来后，视频还停在你隐藏时的位置，不会自己接着播放。想接着看，幽灵模式下按一下视频控制的「播放/暂停」键（默认轻按右 ⌥，即右侧的 Option 键），不用切换到 Mochi；悬浮模式下直接在网页上点播放。也可以回到普通模式，在网页上点播放。

这样设计是因为你回来时，往往要先看清画面、想起刚才看到哪儿，再决定什么时候继续。见[幽灵模式为什么这样设计](../explanation/ghost-mode-design.md#为什么隐藏时暂停视频恢复时却不自动播放)。

视频控制的按键可以在「设置 › 热键 › 视频控制」里修改，见[不切换应用就能控制视频](video-control.md)。

## 隐藏和关闭窗口的区别

| | 隐藏窗口 | 关闭窗口 |
|---|---|---|
| 怎么做 | 悬浮模式或幽灵模式下按 ⌥H，或托盘「隐藏窗口」 | 普通模式或悬浮模式下按 ⌘W，或选「文件 › 关闭窗口」；普通模式下也可以点红色按钮 |
| 网页 | 继续运行，视频暂停 | 关掉，停止播放 |
| 怎么回来 | 再按 ⌥H，或回到普通模式 | 托盘「打开窗口」，或点 Dock 里的 Mochi 图标 |
| 回来后 | 还是原来那个网页，停在隐藏时的位置 | 按「设置 › 通用 › 启动时」的选择重新加载网页，回到普通模式；窗口的位置和大小保留 |

关闭窗口后 Mochi 仍然在运行，菜单栏里的图标还在。这时 ⌥F、⌥G 和 ⌥H 都没有作用，要先把窗口打开。

## 改成别的键

⌥H 可以在「设置 › 热键 › 全局热键」里改成别的组合键，见[修改全局热键](global-hotkeys.md)。
