# 升级 Mochi

升级就是退出旧版，再把新版拖进「应用程序」把旧的替换掉。你的设置、历史记录、书签和登录状态都存在应用之外，升级后都会保留。

Mochi 不会自动检查更新。想知道自己用的是哪一版，选择菜单栏的「Mochi › 关于 Mochi」。

## 下载新版

到 [Releases](https://github.com/asfamilybank/mochi/releases) 下载最新的 `Mochi-x.y.z.dmg`。

## 替换旧版

1. 退出 Mochi：选择菜单栏的「Mochi › 退出 Mochi」，或者按 ⌘Q（Command + Q）。处于幽灵模式时，点菜单栏里的 Mochi 图标，在托盘菜单里选择「退出」。只关掉窗口不算退出，Mochi 还会留在菜单栏里。
2. 双击下载好的 dmg 挂载它，把里面的 `Mochi.app` 拖进旁边的「应用程序」快捷方式。
3. 系统问是否替换已有的同名项目时，选择「替换」。
4. 在访达侧边栏里推出 Mochi 的磁盘映像。

## 第一次打开新版

新版是重新下载的，第一次打开时系统会像第一次安装那样再拦一次。按 [README 的「安装」一节](../../../README.md#安装)里的任一种方式放行即可，之后就不会再问。为什么会这样，见[为什么第一次打开会被拦下](../explanation/unsigned-app.md)。

## 重新添加辅助功能权限

如果你给 Mochi 开过「辅助功能」权限（只有视频控制用了不带 ⌃（Control）也不带 ⌘ 的组合键时才需要，比如 ⌥P（Option + P）），每次升级后都要重新添加一次：

1. 打开「系统设置 › 隐私与安全性 › 辅助功能」。
2. Mochi 的开关看着还开着，但对新版已经不起作用。在列表里选中 Mochi，点下方的「−」把它移除。只把开关关掉再打开没有用。
3. 点「+」，选择「应用程序」里的 `Mochi.app` 添加进来，打开它的开关。

不用重新打开 Mochi，马上就会生效。没开过这项权限的话，这一步可以跳过。为什么每次都要这样做，见[为什么第一次打开会被拦下](../explanation/unsigned-app.md#为什么每次升级后都要把辅助功能移除再重新添加)。

## 升级后会保留什么

设置、历史记录、书签、各网站的登录状态和网站数据都不在 `Mochi.app` 里面，替换应用不会动它们。具体存在哪里，见 [Mochi 存放的数据与系统权限](../reference/data-and-permissions.md)。
