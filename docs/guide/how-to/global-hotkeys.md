# 修改全局热键

Mochi 有两个全局热键，在任何应用里按下都有效：

| 功能 | 默认 | 作用 |
|---|---|---|
| 切换幽灵模式 | ⌥G（Option + G） | 进入或退出[幽灵模式](ghost-mode.md) |
| 隐藏窗口 | ⌥H（Option + H） | 幽灵模式下让窗口完全看不见，再按一次恢复，相当于老板键，见[一键隐藏窗口（老板键）](hide-window.md) |

窗口关着的时候，这两个热键都没有作用。

## 默认热键的代价

全局热键会占用这个组合：只要 Mochi 在运行，你在别的应用里按 ⌥G、⌥H，那个应用都收不到，不管 Mochi 这时是在普通模式、幽灵模式，还是窗口关着。

在常用的英文键盘布局下，⌥G 本来会打出“©”，⌥H 本来会打出“˙”。所以 Mochi 运行时，这两个字符在其他应用里打不出来。需要经常打这两个字符的话，把热键改成别的组合。

默认热键为什么选了这两个，见[按键是怎么被 Mochi 听到的](../explanation/how-keys-are-heard.md#为什么默认热键避开了系统常用的快捷键)。

## 改成别的组合键

1. 按 ⌘,（Command + 逗号），或者点菜单栏里的 Mochi 图标（托盘图标），选「设置…」，打开「设置 › 窗口模式 › 全局热键」。
2. 点「切换幽灵模式」或「隐藏窗口」右边的录制框，框里出现「按下组合键…」。
3. 按下新的组合键。录下就生效：新的组合马上可以用，旧的组合马上还给其他应用。

规则：

- 全局热键只能是组合键，不能设成轻按或连按两次。
- 组合键至少要带 ⌃（Control）、⌥、⌘ 之一。只有 F1 到 F20 这些功能键可以只带 ⇧（Shift），比如 ⇧F5。
- 录制时按 Esc 取消，原来的热键保持不变。点设置窗口里的其他地方，或者切换到别的窗口，也会取消。
- 录制时按 ⌫（Delete），或者不在录制时点录制框右边的 ⓧ，会清除这个热键。清除后这个功能就没有热键了：切换幽灵模式还可以用工具栏按钮和托盘菜单里的「幽灵模式」，隐藏窗口还可以用托盘菜单里的「隐藏窗口」。

选组合时要注意：Mochi 只能发现别的应用注册成全局热键的组合（这时会提示「已被其他应用占用」），发现不了别的应用菜单里的快捷键。如果你选的组合正好是某个应用菜单里的快捷键，Mochi 照样会占用它，那个应用里的这个快捷键就失灵了。所以录之前，先想想你常用的应用里有没有用到这个组合。

改完之后，托盘菜单里「幽灵模式」「隐藏窗口」旁边，以及空页面的「热键」速览里，显示的都是新的组合。

## 提示是什么意思

录下的组合不能用时，Mochi 不会改动这个热键，而是在这一行的名称下面用红字说明原因，几秒后消失：

| 提示 | 意思 | 怎么做 |
|---|---|---|
| 已被其他应用占用 | 别的应用已经把这个组合注册成了它的全局热键，系统不让 Mochi 再用 | 换一个组合，或者先在那个应用里把它的热键改掉 |
| 这是 Mochi 菜单里的快捷键 | 这个组合是 Mochi 菜单里的快捷键，比如 ⌘L | 换一个组合，哪些组合不能用见[快捷键与热键](../reference/shortcuts.md#不能设成热键的组合) |
| 与「隐藏窗口」冲突、与「切换幽灵模式」冲突 | 这个组合已经是另一个全局热键 | 换一个组合，或者先改另一个热键 |
| 与视频控制「播放/暂停」冲突（或「后退」「前进」） | 视频控制里用了这个组合键 | 换一个组合，或者先改视频控制，见[不切换应用就能控制视频](video-control.md#修改按键) |
| 与映射「…」冲突 | 热键传递里有一条映射用这个组合当触发键 | 换一个组合，或者先删掉那条映射，见[把热键变成网页按键](hotkey-forwarding.md#修改和删除映射) |
| 组合键至少要有 ⌃ ⌥ ⌘ 之一 | 只按了普通键，或者只带了 ⇧ | 带上 ⌃、⌥、⌘ 之一再按 |

## 恢复默认热键

「设置 › 窗口模式」最下面的「恢复默认热键」会把下面这些全部恢复成默认值：

- 两个全局热键：⌥G、⌥H，清除过的也会恢复；
- 视频控制的三个按键：轻按右 ⌥（右侧的 Option 键）、连按两次右 ⌘（右侧的 Command 键）、连按两次右 ⌥；
- 后退/前进步长：5 秒。

它不会删除热键传递的映射，也不会改动透明度。所有这些都已经是默认值时，这个按钮是灰的。

### 提示「部分默认热键无法恢复」

点「恢复默认热键」后弹出「部分默认热键无法恢复」，意思是提示里列出的功能，它的默认组合（⌥G 或 ⌥H）现在被别的应用占用了，或者被你的某条映射用作了触发键。这几个功能保留原来的设置，其余的都已经恢复。

想把它们也恢复成默认值：

1. 如果是你的映射用了 ⌥G 或 ⌥H，在「设置 › 窗口模式 › 热键传递」里删掉那条映射。
2. 如果是别的应用占用了，先退出那个应用，或者在那个应用里把它的热键改掉。
3. 再点一次「恢复默认热键」。

## 启动时提示「部分热键注册失败」

打开 Mochi 时弹出「部分热键注册失败」，说明提示里列出的热键这次没能生效，因为别的应用先占用了这个组合。怎么处理，见[按 ⌥G / ⌥H 没反应，或启动时提示部分热键注册失败](troubleshooting.md#按-g--h-没反应或启动时提示部分热键注册失败)。
