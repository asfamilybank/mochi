# 故障排除

按症状查找。每一条都按同样的顺序写：

- **症状**：你看到了什么。
- **原因**：一句话说明为什么会这样，需要展开时链接到原理说明。
- **怎么做**：一步步照着做。

## 安装与升级

### 第一次打开被系统拦下

**症状**：第一次双击打开 `Mochi.app`，系统提示无法验证开发者，或者无法确认它是否含有恶意软件，Mochi 没有打开。

**原因**：Mochi 目前没有经过苹果公证，从网上下载的这类应用第一次打开时都会被系统拦下。这是预期内的，不是下载坏了。为什么会这样、放行是否安全，见[为什么第一次打开会被拦下](../explanation/unsigned-app.md)。

**怎么做**：按 [README 的「安装」一节](../../../README.md#安装)里的两种方式之一放行一次：在「系统设置 › 隐私与安全性」里点「仍要打开」，或者在终端里去掉隔离标记。放行之后，以后每次打开都不会再问。升级到新版本后第一次打开时会再被拦一次，同样放行一次就好，见[升级 Mochi](upgrade.md)。

### 升级后辅助功能开着，却不起作用

**症状**：升级 Mochi 之后，「系统设置 › 隐私与安全性 › 辅助功能」里 Mochi 的开关显示是打开的，可视频控制里不带 ⌃（Control）也不带 ⌘（Command）的组合键（比如 ⌥P，即 Option + P）还是没反应，「设置 › 幽灵模式」顶部也还在提示「需要辅助功能权限」。

**原因**：系统按每一版 Mochi 的签名记下这项权限，那个开着的开关记的是旧版，对新版不起作用。为什么会这样，见[为什么第一次打开会被拦下](../explanation/unsigned-app.md#为什么每次升级后都要把辅助功能移除再重新添加)。

**怎么做**：

1. 打开「系统设置 › 隐私与安全性 › 辅助功能」。
2. 在列表里选中 Mochi，点下方的「−」把它移除。只把开关关掉再打开没有用。
3. 点「+」，选择「应用程序」里的 `Mochi.app` 添加进来，打开它的开关。

不用重新打开 Mochi，马上就会生效。以后每次升级都要这样做一次，见[升级 Mochi](upgrade.md)。

## 热键与视频控制

### 幽灵模式下，视频控制的组合键（如 ⌥P）没反应

**症状**：你把视频控制的某个按键设成了不带 ⌃（Control）也不带 ⌘（Command）的组合键，比如 ⌥P（Option + P）或 ⇧F5（Shift + F5），在幽灵模式下、在别的应用里按它，视频没反应。

**原因**：系统把这类组合键当成打字，只让获得「辅助功能」权限的应用在其他应用里听到它。默认的轻按、连按两次，以及带 ⌃ 或 ⌘ 的组合键都不需要任何权限。

**怎么做**：

1. 缺这项权限时，「设置 › 幽灵模式」顶部会显示「需要辅助功能权限」，托盘菜单里也会出现「视频控制需要辅助功能权限…」。
2. 提示旁的按钮是「请求权限」就点它，按系统的提示打开；是「打开系统设置」就点它，在「系统设置 › 隐私与安全性 › 辅助功能」里打开 Mochi 的开关。打开后马上生效，不用重新打开 Mochi。
3. 如果 Mochi 的开关本来就开着，多半是升级后失效了，见[升级后辅助功能开着，却不起作用](#升级后辅助功能开着却不起作用)。

不想给这项权限的话，把这个按键改成轻按、连按两次，或者带 ⌃ 或 ⌘ 的组合键。各项权限什么时候需要，见 [Mochi 存放的数据与系统权限](../reference/data-and-permissions.md#系统权限)。

### 按 ⌥G / ⌥H 没反应，或启动时提示部分热键注册失败

**症状**：按 ⌥G（Option + G）进不了幽灵模式，或者在幽灵模式下按 ⌥H 窗口没有隐藏；打开 Mochi 时，可能还弹出过「部分热键注册失败」或「部分映射注册失败」。

**原因**：多数是下面几种情况之一：窗口关着；在普通模式下按了 ⌥H；热键已经被改掉或清除了；或者打开 Mochi 时，别的应用已经先占用了这个组合。

**怎么做**：

1. 窗口关着时，两个全局热键都没有作用。点菜单栏里的 Mochi 图标（托盘图标），选「打开窗口」。
2. ⌥H 只在幽灵模式下有效，普通模式下按它没有反应，见[一键隐藏窗口（老板键）](hide-window.md#为什么只在幽灵模式下有效)。
3. 点托盘图标，看「幽灵模式」「隐藏窗口」旁边显示的组合，那是当前生效的热键；旁边什么都没有，说明热键被清除了。也可以打开「设置 › 幽灵模式 › 全局热键」查看。
4. 弹出过「部分热键注册失败」时，提示里列出的热键这次没能生效：别的应用先占用了这个组合，Mochi 拿不到。任选一种办法：
   - 在「设置 › 幽灵模式 › 全局热键」里把它改成别的组合，马上生效，见[修改全局热键](global-hotkeys.md)；
   - 或者退出占用它的那个应用，再退出并重新打开 Mochi。Mochi 只在打开时申请一次这些热键，所以要重新打开才能拿回来。
5. 弹出过「部分映射注册失败」时，提示里只说有几条映射的触发键被别的应用或 Mochi 自己的热键占用了，不说是哪几条。没能生效的只会是触发键是组合键的映射，也就是「设置 › 幽灵模式 › 热键传递」里带锁形图标的那几行；轻按和连按两次不会注册失败。这样找出是哪几条：
   - 把带锁形图标的映射逐条删掉，再用同一个触发键和同一个网页按键重新添加。
   - 添加那一行下面出现红字的，就是冲突的那条，红字会说明原因，比如「已被其他应用占用」。这时换一个触发键，或者改用「轻按」「连按两次」再添加。
   - 能添加成功的，说明这条现在已经生效，不用再管。

   怎么删除和添加映射，见[把热键变成网页按键](hotkey-forwarding.md#修改和删除映射)。

不知道是哪个应用占用了时，可以试着换一个同时按两三个修饰键的组合。

如果是视频控制的按键没反应，见[幽灵模式下，视频控制的组合键（如 ⌥P）没反应](#幽灵模式下视频控制的组合键如-p没反应)。

### 别的应用里打不出 © / ˙，或某个组合键失灵了

**症状**：Mochi 运行时，在别的应用里按 ⌥G、⌥H 打不出“©”“˙”；或者某个应用里原本好用的组合键，按了没反应。

**原因**：这个组合被 Mochi 占用了。全局热键，以及触发键是组合键的映射，只要 Mochi 在运行就会占用这个组合，不管是不是在幽灵模式、窗口开没开，别的应用都收不到它。Mochi 只能发现别的应用注册成全局热键的组合，发现不了别的应用菜单里的快捷键，所以撞上时不会有任何提示。见[按键是怎么被 Mochi 听到的](../explanation/how-keys-are-heard.md#为什么占用会让这个组合在其他应用里失灵)。

**怎么做**：

1. 打开「设置 › 幽灵模式」，看「全局热键」分组里的两个热键，以及「热键传递」分组里带锁形图标的映射，找出失灵的那个组合。
2. 是全局热键的话，在「全局热键」里把它改成别的组合，见[修改全局热键](global-hotkeys.md#改成别的组合键)。
3. 是映射的话，删掉它，再用别的组合键，或者用「轻按」「连按两次」重新添加；轻按和连按两次不会占用任何组合。见[把热键变成网页按键](hotkey-forwarding.md#组合键会被占用轻按和连按两次不会)。
4. 只是临时要打这几个字符，也可以先退出 Mochi，打完再打开。

视频控制的按键不会占用任何组合，不会让别的应用里的按键失灵。反过来，视频控制的组合键会在你正在用的应用里照常起作用，比如设成 ⌥P 时，在输入框里按它会打出“π”；不想这样，就换成轻按、连按两次，或者一个在你常用的应用里没有用处的组合，见[不切换应用就能控制视频](video-control.md#用组合键时要注意)。

## 窗口与幽灵模式

### 窗口找不到了

**症状**：Mochi 还在运行，菜单栏里有 Mochi 图标，但屏幕上看不到它的窗口。

**原因**：通常是下面几种之一：窗口在幽灵模式下被隐藏了；幽灵模式的透明度调得太低；窗口在另一个桌面上，或者被最小化了；窗口已经关闭。

**怎么做**：

1. 点菜单栏里的 Mochi 图标，看弹出的菜单：
   - 「隐藏窗口」前面有勾：窗口被隐藏了。点「隐藏窗口」，或者按 ⌥H（Option + H），窗口就会回来。你改过这个热键的话，按你设的那个。
   - 「幽灵模式」前面有勾、「隐藏窗口」前面没有：窗口处于幽灵模式，但可能调得太透明，或者在别的桌面上。点「打开窗口」退出幽灵模式。以后觉得太透明，可以在「设置 › 幽灵模式 › 外观 › 目标透明度」里调高，0% 时完全看不见。
   - 「幽灵模式」是灰的：窗口已经关闭。点「打开窗口」重新打开它。
   - 都不是：点「打开窗口」，把窗口带到最前面。
2. 还是看不到的话：
   - 窗口可能在另一个桌面上。用调度中心（Mission Control）找到它所在的桌面，切过去。
   - 窗口可能被最小化了。点程序坞右侧的 Mochi 窗口缩略图。
3. 仍然找不到，就退出 Mochi 再打开。如果窗口上次的位置已经不在任何一块显示器上（比如拔掉了外接显示器），它会回到主显示器的正中间。

更多说明见[摆放和关闭窗口](window-placement.md)。

### 幽灵模式下点不到网页

**症状**：窗口半透明地浮在最上层，点上去却没有反应，点到的是下面的应用；也拖不动窗口、调不了大小，找不到工具栏。

**原因**：这是幽灵模式本来的设计，不是故障。幽灵模式下点击会穿过窗口，落到下面的应用上，这样网页才不会挡住你手上的事。见[幽灵模式为什么这样设计](../explanation/ghost-mode-design.md#为什么幽灵模式里不能点网页)。

**怎么做**：

1. 退出幽灵模式：按 ⌥G（Option + G），或者点菜单栏里的 Mochi 图标，选「幽灵模式」或「打开窗口」。
2. 窗口恢复成普通窗口后，照常操作网页。
3. 操作完想回到幽灵模式，再按一次 ⌥G。

如果你只是想暂停、播放或快进视频，不用退出幽灵模式，用视频控制就行，在「设置 › 幽灵模式 › 视频控制」里设置按键，见[不切换应用就能控制视频](video-control.md)。想用网站自带的快捷键，用「设置 › 幽灵模式 › 热键传递」，见[把热键变成网页按键](hotkey-forwarding.md)。

更多说明见[用幽灵模式让网页浮在最上层](ghost-mode.md#幽灵模式下不能做的事)。

### 隐藏窗口后视频停了，恢复后没有继续播放

**症状**：按 ⌥H（Option + H）隐藏窗口时，视频或声音停了；再按一次让窗口回来，视频还是暂停着。

**原因**：这是设计如此。隐藏窗口时，Mochi 会暂停网页里所有正在播放的视频和音频，让它停在你离开的位置；窗口回来时不会自动接着播放，什么时候继续由你决定。见[幽灵模式为什么这样设计](../explanation/ghost-mode-design.md#为什么隐藏时暂停视频恢复时却不自动播放)。

**怎么做**：

- 按一下视频控制的「播放/暂停」键（默认轻按右 ⌥，即右侧的 Option 键），视频就接着播放，不用切换到 Mochi。
- 或者退出幽灵模式，在网页上点播放。

如果按「播放/暂停」键也没有反应，打开「设置 › 幽灵模式 › 视频控制」，确认「播放/暂停」设了按键；面板顶部出现「需要辅助功能权限」时，按提示处理。怎么修改按键，见[不切换应用就能控制视频](video-control.md#修改按键)。

更多说明见[一键隐藏窗口（老板键）](hide-window.md#恢复后视频不会自动继续播放)。

## 网页与网站

### 打开网页就自动出声

**症状**：打开 Mochi，或者打开某个网页时，视频或声音不等你点就自己播放起来。

**原因**：「设置 › 网站 › 通用 › 自动播放」默认是「允许全部自动播放」，这样重新打开 Mochi、回到上次看的视频网页时，视频能接着播。

**怎么做**：

1. 按 ⌘,（Command + 逗号）打开设置，切到「网站」面板，在左边选「通用」。
2. 把「自动播放」改成「停止有声媒体」（带声音的要你点了才播放，静音的仍可以自己播放），或者「永不自动播放」（全部都要你点了才播放）。
3. 这一项要下次打开窗口时才生效。想马上生效，点下面的「重新打开窗口」。

如果只是不想一打开 Mochi 就回到上次的视频网页，也可以在「设置 › 通用」里把「启动时」改成「使用空页面」。

### 网站提示浏览器版本过低

**症状**：某个网站在 Mochi 里打不开，提示“浏览器版本过低”“请升级浏览器”之类，或者自动跳到一个升级提示页；同一个网站在 Safari 里正常。

**原因**：Mochi 跟网站报告的身份，是你这台 Mac 上装的 Safari 及其版本，网站通常会把它当成 Safari 正常对待。仍然出现这个提示，可能是网站之前存下的旧缓存还在用，也可能是这个网站对浏览器另有要求。

**怎么做**：

1. 先只清缓存，这不会让你退出登录：选择「历史记录 › 清除浏览数据…」，「时间范围」选「时间不限」，只勾选「缓存的图片和文件」，取消勾选「历史记录」和「Cookie 和网站数据」（这两项默认是勾着的），再点「清除」。
2. 按 ⌘R（Command + R）或者选「显示 › 重新载入页面」刷新页面。清除后当前页面不会自己刷新。
3. 还是不行，就删除这个网站的网站数据，这会让你退出这个网站的登录：按 ⌘, 打开设置，在「隐私与安全性 › 网站数据」里点「管理网站和数据…」，搜索并选中这个网站，点「删除数据」，然后再刷新页面。
4. 如果你的 macOS 不是最新版，Safari 也就不是最新版，可以先在「系统设置 › 通用 › 软件更新」里更新系统再试。
5. 都不行，请选「帮助 › 反馈问题…」告诉我们是哪个网站。

### 某个网站登录不了，或者一直不正常

**症状**：在某个网站上点登录没反应、登录后又退出、页面一直转圈或显示不正常，同一个网站在 Safari 里正常。

**原因**：常见的有三种：处于幽灵模式时登录小窗不会打开；网站在你没点任何东西时就弹出登录窗口，被「弹出式窗口」设置挡住了；或者这个网站之前存在 Mochi 里的网站数据出了问题。

**怎么做**：

1. 如果窗口处于幽灵模式，先按 ⌥G（Option + G）退出，再点登录。
2. 删除这个网站的网站数据，然后重新登录：按 ⌘,（Command + 逗号）打开设置，在「隐私与安全性 › 网站数据」里点「管理网站和数据…」，搜索并选中这个网站，点「删除数据」，再按 ⌘R（Command + R）刷新页面。列表里是按整个域名列出的，比如删除 `google.com` 的数据会让你退出所有 Google 旗下网站的登录。
3. 点了登录按钮却什么都没弹出来，可以临时把「设置 › 网站 › 通用 › 弹出式窗口」改成「允许」，登录完再改回「阻止」。
4. 都不行，请选「帮助 › 反馈问题…」告诉我们是哪个网站。

登录小窗、「弹出式窗口」设置和退出登录的说明，见[登录网站](sign-in.md)。

## 系统权限

### 在系统设置里打开了摄像头、麦克风或文件和文件夹权限，Mochi 里还是用不了

**症状**：之前拒绝过 Mochi 使用摄像头、麦克风或「下载」文件夹，后来在「系统设置 › 隐私与安全性」里把它打开了，可 Mochi 里的网页还是用不了，设置里的提示也没有消失。

**原因**：这几项权限只要被拒过一次，系统就要等 Mochi 重新打开，才把新的设置交给它。反过来也一样：Mochi 正在用的时候在系统设置里关掉，也要重新打开 Mochi 才会被拒。

**怎么做**：

1. 系统提示需要退出并重新打开 Mochi 时，请照做。
2. 如果当时选了「以后」，就自己退出 Mochi（菜单栏的「Mochi › 退出 Mochi」，或者托盘菜单里的「退出」），再打开一次。只关掉窗口不算重新打开。

重新打开 Mochi 之后，网页还是用不了摄像头或麦克风的话，系统这一关已经过了，再看看 Mochi 自己这一关：

- 打开「设置 › 网站 › 摄像头」（或「麦克风」），看这个网站在「已配置的网站：」列表里是不是「拒绝」；不在列表里的，看「访问其他网站时」是不是「拒绝」。改成「询问」或「允许」。
- 窗口处于幽灵模式时，Mochi 窗口里的网页要用摄像头、麦克风会被直接拒绝，先按 ⌥G（Option + G）退出幽灵模式。
- 改了上面的设置后，按 ⌘R（Command + R）刷新一次网页，再让网页重新请求摄像头。

见[让网页使用摄像头和麦克风](camera-and-microphone.md)。

辅助功能不受这一条影响，打开就生效；它没反应时，见[幽灵模式下，视频控制的组合键（如 ⌥P）没反应](#幽灵模式下视频控制的组合键如-p没反应)。

## 设置

### 启动时提示配置文件读取失败

**症状**：打开 Mochi 时弹出「配置文件读取失败」，说某个文件无法解析，已使用默认设置启动。

**原因**：保存设置的那个文件损坏了，或者被手动改坏了，Mochi 读不懂它，只好先用默认设置启动。历史记录、书签和网站的登录状态不存在这个文件里，不受影响。

**怎么做**：

1. **想保留原来的设置**：在做任何其他操作之前，先把提示里写的那个文件复制一份到别处，比如桌面。在访达里按 ⇧⌘G（Shift + Command + G），粘贴提示里的路径，就能找到它。

   这一步要赶在 Mochi 下一次保存设置之前：你改任何一项设置、在地址栏打开网页、关闭窗口或者退出 Mochi 时，Mochi 都会用当前的默认设置覆盖这个文件。
2. **不在意原来的设置**：直接在「设置」里重新设好。Mochi 保存时会写出一份能正常读取的新文件，下次启动就不会再提示。
3. **想找回原来的设置**：复制出来的那份是文本文件。熟悉它的格式的话，可以修好后，在 Mochi **退出的状态下**放回原处，再打开 Mochi；Mochi 运行时放回去的会被覆盖。不知道怎么修，可以到 [GitHub Issues](https://github.com/asfamilybank/mochi/issues) 反馈问题，附上提示里的完整文字。如果要附上这个文件，先删掉你不想公开的内容，比如上次访问的网址、自定义脚本。
