## 窗口与幽灵模式

### 幽灵模式下点不到网页

**症状**：窗口半透明地浮在最上层，点上去却没有反应，点到的是下面的应用；也拖不动窗口、调不了大小，找不到工具栏。

**原因**：这是幽灵模式本来的设计，不是故障。幽灵模式下点击会穿过窗口，落到下面的应用上，这样网页才不会挡住你手上的事。详见[幽灵模式为什么这样设计](../explanation/ghost-mode-design.md#为什么幽灵模式里不能点网页)。

**怎么做**：

1. 退出幽灵模式：按 ⌥G（Option + G），或者点菜单栏里的 Mochi 图标，选「幽灵模式」或「打开窗口」。
2. 窗口恢复成普通窗口后，照常操作网页。
3. 操作完想回到幽灵模式，再按一次 ⌥G。

如果你只是想暂停、播放或快进视频，不用退出幽灵模式，用视频控制就行，在「设置 › 幽灵模式 › 视频控制」里设置按键。想用网站自带的快捷键，用「设置 › 幽灵模式 › 热键传递」。

更多说明见[用幽灵模式让网页浮在最上层](ghost-mode.md#幽灵模式下不能做的事)。

### 隐藏窗口后视频停了，恢复后没有继续播放

**症状**：按 ⌥H（Option + H）隐藏窗口时，视频或声音停了；再按一次让窗口回来，视频还是暂停着。

**原因**：这是设计如此。隐藏窗口时，Mochi 会暂停网页里所有正在播放的视频和音频，让它停在你离开的位置；窗口回来时不会自动接着播放，什么时候继续由你决定。详见[幽灵模式为什么这样设计](../explanation/ghost-mode-design.md#为什么隐藏时暂停视频恢复时却不自动播放)。

**怎么做**：

- 按一下视频控制的「播放/暂停」键（默认轻按右 ⌥，即右侧的 Option 键），视频就接着播放，不用切换到 Mochi。
- 或者退出幽灵模式，在网页上点播放。

如果按「播放/暂停」键也没有反应，打开「设置 › 幽灵模式 › 视频控制」，确认「播放/暂停」设了按键；面板顶部出现「需要辅助功能权限」时，按提示处理。

更多说明见[一键隐藏窗口（老板键）](hide-window.md#恢复后视频不会自动继续播放)。
