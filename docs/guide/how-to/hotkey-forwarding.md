# 把热键变成网页按键

很多视频网站都有自己的键盘快捷键，比如开关弹幕、全屏、下一集。热键传递让你在幽灵模式下按一个你设定的触发键，Mochi 就替你向网页按下对应的键，你不用切换到 Mochi 也能用上这些快捷键。

热键传递里的每一条设置叫一条映射：一个触发键，加上要发给网页的按键。

## 热键传递还是视频控制

| | 视频控制 | 热键传递 |
|---|---|---|
| 做什么 | 直接暂停、播放、后退、前进页面里的视频 | 向网页发送一个按键，效果由网站决定 |
| 适用的网站 | 所有网站 | 网站要有对应的键盘快捷键 |
| 默认 | 开箱就有三个按键 | 没有映射，要自己添加 |
| 会不会占用按键 | 从不占用 | 触发键是组合键时会占用 |

只想暂停、播放、后退、前进，用[视频控制](video-control.md)就够了，它不依赖网站的快捷键，换一个网站也照样能用。想用网站特有的功能（弹幕、字幕、下一集这类），再用热键传递。

## 添加一条映射

1. 先在网站的帮助或快捷键说明里查到你要的按键，比如某个网站用 D 开关弹幕。
2. 按 ⌘,（Command + 逗号），或者点菜单栏里的 Mochi 图标（托盘图标），选「设置…」，打开「设置 › 幽灵模式 › 热键传递」。分组最下面那一行用来添加映射。
3. 在这一行最左边的下拉菜单里选触发方式：「组合键」（默认）、「轻按」或「连按两次」。选好后，旁边的录制框马上开始录制，按下你想用的触发键。
4. 点箭头右边的录制框，看到「按下按键…」后，按下要发给网页的键。这个键不需要带修饰键，单独一个字母也行。
5. 点「添加映射」。两个键都录好之后它才能点。添加后马上生效。

录制的规则跟视频控制一样：按 Esc 取消，按 ⌫（Delete）清除录制框里的键；触发键是组合键时至少要带 ⌃（Control）、⌥（Option）、⌘ 之一（F1 到 F20 可以只带 ⇧（Shift））。因为 Esc 和 ⌫ 在录制时有这两个用处，要发给网页的键不能是单独的 Esc、⌫ 或 ⌦（向前删除），带上修饰键就可以。

## 修改和删除映射

已经添加的映射列在分组上方，每行左边是触发键，箭头右边是发给网页的按键。映射不能直接修改，想改就先删除，再重新添加一条。

删除：点那一行右边的垃圾桶按钮（「删除映射」）。删除后马上生效，如果触发键是组合键，这个组合也马上还给其他应用。

## 组合键会被占用，轻按和连按两次不会

- **触发键是组合键**：只要 Mochi 在运行，这个组合就会从所有应用手里被拿走，不管是不是在幽灵模式、窗口开没开。你在别的应用里按它，那个应用收不到。这样的映射旁边有一个锁形图标，鼠标停在上面会显示「这个组合会被占用，其他应用里按不出来」；在添加那一行选「组合键」时，下面也写着这句话。
- **触发键是轻按或连按两次**：Mochi 只在旁边听着，不占用。这个键照常传给你正在用的应用，而单独按一下修饰键本来就不会打出字符。

所以，如果你不想有任何组合在别的应用里失灵，就选「轻按」或「连按两次」。选组合键的话，尽量选一个你在其他应用里用不到的组合。为什么有这个区别，见[按键是怎么被 Mochi 听到的](../explanation/how-keys-are-heard.md)。

轻按和连按两次跟视频控制共用同一套识别：同一颗修饰键，一边设「轻按」、另一边设「连按两次」是可以的，代价是这颗键的轻按要等约 0.3 秒才触发；两边设成完全一样的触发键则算冲突。

热键传递不需要任何系统权限。

## 什么时候生效

- 只在幽灵模式下生效，窗口隐藏时也生效。
- 普通模式下按触发键没有作用。注意组合键这时照样被占用。
- Mochi 窗口不会因此获得焦点，你正在用的应用一直留在前台。网页收到的按键，跟你在网页上直接按下这个键一样。

按键会发给网页上当前拿着键盘焦点的地方。Mochi 自带的官方内置适配脚本「通用视频对焦适配」默认打开，它在网页加载完后把键盘焦点交给网页上的第一个视频，这样按键会落到播放器上。关掉它之后，按键可能落到搜索框之类的地方，见[用脚本和样式表调整网页](scripts.md#官方内置适配脚本)。

按了触发键网页却没反应，先确认「通用视频对焦适配」是打开的；再退出幽灵模式，在网页上直接按一下要发送的那个键，确认网站本身支持这个快捷键。

## 提示是什么意思

### 添加时的提示

添加不成功时，添加那一行下面会用红字说明原因，几秒后消失：

| 提示 | 意思 | 怎么做 |
|---|---|---|
| 与「切换幽灵模式」冲突、与「隐藏窗口」冲突 | 这个组合是 Mochi 的全局热键 | 换一个触发键，或者先[修改全局热键](global-hotkeys.md) |
| 与视频控制「播放/暂停」冲突（或「后退」「前进」） | 视频控制里已经用了一模一样的触发键 | 换一个触发键，或者先在「设置 › 幽灵模式 › 视频控制」里改掉，见[不切换应用就能控制视频](video-control.md#修改按键) |
| 与映射「…」冲突 | 已经有一条映射用了这个触发键 | 换一个触发键，或者先删掉那条映射 |
| 这是 Mochi 菜单里的快捷键 | 这个组合是 Mochi 菜单里的快捷键，比如 ⌘R | 换一个，哪些组合不能用见[快捷键与热键](../reference/shortcuts.md#不能设成热键的组合) |
| 已被其他应用占用 | 别的应用已经把这个组合注册成了它的全局热键 | 换一个触发键 |
| 组合键至少要有 ⌃ ⌥ ⌘ 之一 | 录制组合键时只按了普通键，或者只带了 ⇧ | 带上 ⌃、⌥、⌘ 之一再按 |
| 请轻按一颗修饰键 | 录制轻按或连按两次时按了普通键 | 单独按一下修饰键 |

### 启动时提示「部分映射注册失败」

打开 Mochi 时弹出「部分映射注册失败」，说明有几条触发键是组合键的映射，这次没能生效：它们的组合已经被其他应用，或者被 Mochi 自己的全局热键占用了。怎么处理，见[按 ⌥G / ⌥H 没反应，或启动时提示部分热键注册失败](troubleshooting.md#按-g--h-没反应或启动时提示部分热键注册失败)。
