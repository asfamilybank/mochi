# 用悬浮模式边看边用网页

悬浮模式让 Mochi 窗口只剩网页内容、变成半透明、浮在其他窗口上面，同时仍然像普通窗口一样可以点击、输入。适合一边在别的应用里工作，一边随时在网页里点一下、打几个字，比如看着聊天、查着资料。

只想看、不想碰，用[幽灵模式](ghost-mode.md)：它的点击会穿过窗口，完全不打扰你正在用的应用。

## 进入悬浮模式

任选一种：

- 按 ⌥F（Option + F）。这是「切换悬浮模式」的全局热键，在任何应用里按都有效，可以改成别的组合，见[修改全局热键](global-hotkeys.md)。
- 点菜单栏里的 Mochi 图标（托盘图标），选「悬浮模式」。

窗口关着的时候进不了悬浮模式：托盘里的「悬浮模式」是灰的，按 ⌥F 也没有反应。先用托盘的「打开窗口」把窗口打开。

## 进入后会发生什么

下面几件事总是一起发生：

- **工具栏隐藏**：交通灯按钮、地址栏和所有工具栏按钮都不见了，只剩网页内容。网页在屏幕上的位置和大小不变，窗口只是收起了顶部的工具栏。
- **变透明**：窗口降到你设定的透明度，默认是 80%。
- **置顶**：窗口浮在其他应用的窗口上面。不想置顶的话，可以在设置里关掉，见下面的[不让悬浮窗口置顶](#不让悬浮窗口置顶)。
- **可以操作**：Mochi 成为前台应用，你可以直接点网页、在网页里打字、滚动网页。切到别的应用后，焦点像普通窗口一样离开 Mochi，窗口仍然浮在上面。

## 退出悬浮模式

任选一种：

- 再按一次 ⌥F。
- 点菜单栏里的 Mochi 图标，选「悬浮模式」（进入悬浮模式后它前面有一个勾）。
- 点菜单栏里的 Mochi 图标，选「打开窗口」。
- 点 Dock 里的 Mochi 图标。

退出后窗口恢复成普通窗口：工具栏回来、不再透明、不再置顶。

## 在悬浮模式和幽灵模式之间切换

不用先回到普通模式：

- 在悬浮模式下按 ⌥G（Option + G），直接进入幽灵模式。
- 在幽灵模式下按 ⌥F，直接进入悬浮模式。

## 调整透明度

1. 按 ⌘,（Command + 逗号），或者点菜单栏里的 Mochi 图标，选「设置…」。
2. 打开「设置 › 窗口模式 › 悬浮模式 › 透明度」，拖动滑块。滑块右边显示当前的百分比，数字越小窗口越透明。

松开滑块就生效。正处于悬浮模式时也能调，可以边调边看效果。悬浮模式和幽灵模式的透明度分开设置，互不影响。

悬浮模式的透明度最低是 10%：这时窗口仍然接收点击和键盘输入，完全看不见的话会挡住下面的应用。想让窗口完全看不见，用幽灵模式。

## 移动、调整大小和关闭

悬浮窗口平时看不到标题栏。把鼠标移到窗口顶部边缘附近，标题栏会从网页上方长出来，带着红、黄、绿三个按钮；鼠标离开后它又收回去。标题栏长出和收回时，网页在屏幕上一动不动，也不会重新排版。

- **移动**：按住长出来的标题栏拖动。拖到屏幕边缘会吸附，跟普通模式一样，用的是同一个「设置 › 通用 › 窗口 › 拖动时吸附屏幕边缘」。窗口顶边贴不到屏幕最上沿，总会留出一个标题栏的高度，好让标题栏有地方长出来。
- **调整大小**：直接拖窗口的边缘或角落，不用等标题栏出现。
- **关闭**：点红色按钮，或者按 ⌘W（Command + W）。
- **最小化**：点黄色按钮。
- **全屏、缩放**：不行，绿色按钮是灰的。

窗口隐藏时，鼠标划过它也不会长出标题栏。

## 不让悬浮窗口置顶

1. 按 ⌘,，或者点菜单栏里的 Mochi 图标，选「设置…」。
2. 在「设置 › 窗口模式 › 悬浮模式」里取消勾选「始终置顶」。

立即生效，正处于悬浮模式时窗口马上降下去，之后会被其他应用的窗口盖住，跟普通窗口一样。只能在设置里改，没有对应的热键或菜单项。幽灵模式总是置顶，不受这个设置影响。

置顶时，从悬浮窗口里打开的登录小窗也跟着浮在上面，不会被压在悬浮窗口底下；不置顶或者回到普通模式时，它们也跟着降下去。

## 一键隐藏窗口

按 ⌥H（Option + H），或者在托盘里选「隐藏窗口」，窗口立刻完全看不见，网页上的视频和声音暂停，焦点回到你之前在用的应用。再按一次，窗口回来，但焦点不会被抢回 Mochi：要操作网页时点一下它就行。见[一键隐藏窗口（老板键）](hide-window.md)。

隐藏期间窗口不接收点击，网页发起的请求（对话框、摄像头、下载、登录小窗）按幽灵模式的方式直接处理掉，不弹出任何东西。这时按 ⌥G 切到幽灵模式，窗口仍然保持隐藏。

## 悬浮模式下不能做的事

- 打开地址栏输入网址（「文件 › 打开位置…」）、添加书签（「书签 › 添加书签…」）：悬浮模式没有地址栏，这两个菜单项是灰的。想打开别的网页，可以从「历史记录」或「书签」菜单打开，或者先回到普通模式。
- 全屏：绿色按钮是灰的。
- [视频控制](video-control.md)、[热键传递](hotkey-forwarding.md)只在幽灵模式下有效。

刷新、停止、缩放、返回、前进照常可用，用「显示」「历史记录」菜单或它们的快捷键。

网页发起的请求（对话框、摄像头、下载、登录小窗）跟普通模式一样处理，会照常弹出来问你。

每一项在三种模式下的具体差别，见[三种模式对照](../reference/modes.md)。

## 重新打开 Mochi 后回到普通模式

退出 Mochi 再打开，或者关掉窗口再打开，窗口总是先回到普通模式，不会接着上次的悬浮模式。

## 遇到问题

- [按 ⌥G / ⌥H 没反应，或启动时提示部分热键注册失败](troubleshooting.md#按-g--h-没反应或启动时提示部分热键注册失败)：⌥F 没反应时也按这一条排查。
- [别的应用里打不出 © / ˙，或某个组合键失灵了](troubleshooting.md#别的应用里打不出---或某个组合键失灵了)：⌥F 占用了“ƒ”和终端里的“向后跳一个单词”。
