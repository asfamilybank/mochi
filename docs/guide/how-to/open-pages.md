# 打开网页与设置启动页

这一页讲怎么在 Mochi 里打开网页、换搜索引擎，以及怎么决定每次打开 Mochi 时先看到什么。

下面的操作都在普通模式下进行。幽灵模式下工具栏是隐藏的，菜单里这些项也会变灰，先按 ⌥G（Option + G）退出幽灵模式再操作，见[用幽灵模式让网页浮在最上层](ghost-mode.md)。

## 在地址栏输入网址或直接搜索

地址栏在窗口顶部工具栏的正中间。还没打开过网页时，它显示「搜索或输入网址」；打开网页后，平时显示网页的标题，鼠标移上去或点一下才显示网址。

1. 点一下地址栏，里面的网址会整段选中，直接输入就能替换掉。
2. 输入网址或要搜索的文字。
3. 按 Return（回车）。

Mochi 按你输入的内容决定是打开网址还是搜索：

- **当作网址打开**：像 `bilibili.com`、`www.example.com/path` 这样带点的域名，以及 `localhost`、IP 地址。没写 `https://` 时会自动补上；只能用 `http://` 打开的网站，要把 `http://` 写全。
- **用搜索引擎搜索**：其他内容，比如带空格的一句话、一个单词。用哪个搜索引擎见下面的[换搜索引擎](#换搜索引擎)。

输入到一半想放弃，按 Esc。每按一次退一步：先关掉下面的建议列表，再把地址栏恢复成原来的网址，最后离开地址栏。

### 不用鼠标跳到地址栏

按 ⌘L（Command + L），或者选择菜单栏的「文件 › 打开位置…」，地址栏会被选中，可以直接输入。

- 书签、历史记录或设置窗口在最前面时，这个操作会先把 Mochi 窗口带到前面，再选中地址栏。
- Mochi 窗口已经关闭时，它会先重新打开窗口。

## 地址栏建议从哪里来

在地址栏里输入时，下面会弹出一个建议列表：

- **还没输入时**：列出你的全部书签，顺序跟你在书签窗口里排的一样。没有书签时不显示列表。
- **输入之后**：
  - 第一行是按 Return 会做的事，写着「打开」某个网址，或者「用 Google 搜索」你输入的文字（这里显示的是你选的搜索引擎）。
  - 下面最多 7 条是你访问过的网页和书签。网址或标题里有词以你输入的内容开头，就会列出来；访问得越多、越近的排得越靠前，书签会排得更靠前，还带书签标记。

按 ↑ ↓ 在列表里选，按 Return 打开选中的那一项，也可以直接点某一行。

输入时，Mochi 还会把最可能的网址直接补进地址栏，补出来的部分处于选中状态：

- 想打开补出来的网址，直接按 Return。
- 想打开你自己输入的那个更短的网址，先按一次 ⌫（Delete）删掉补出来的部分，再按 Return。
- 接着输入，补出来的部分会被你输入的字替换掉。

建议只来自这台 Mac 上的书签和最近 90 天的历史记录。按 Return 之前，你输入的内容不会发给搜索引擎或任何网站。清除历史记录之后，建议也会跟着变。

## 换搜索引擎

1. 按 ⌘,（Command + 逗号）打开设置，选「通用」。
2. 在「设置 › 通用 › 搜索 › 搜索引擎」里选一个：Google、Bing、DuckDuckGo、百度。默认是 Google。

改完马上生效，下一次在地址栏搜索就会用新的搜索引擎。

## 设置每次打开时先看到什么

「设置 › 通用 › 启动 URL › 启动时」决定窗口每次打开时先显示什么。这里的“每次打开”指启动 Mochi，以及关闭窗口后重新打开它。

| 选项 | 效果 |
|---|---|
| 「继续上次访问页面」（默认） | 打开你最后一次自己打开的网址：在地址栏里输入的，或者从历史记录、书签打开的。在网页里点链接跳过去的页面不算。从来没打开过网页时，显示空页面。 |
| 「使用空页面」 | 显示空页面。空页面上有一份「热键」速览，列出当前生效的热键。 |
| 「指定网址」 | 每次都打开同一个网址。 |

选「指定网址」时：

1. 在下面的「输入网址」框里输入完整的网址，以 `https://` 或 `http://` 开头。
2. 按 Return 保存。

没按 Return，或者网址没写完整时，这一项不会保存，下次打开窗口时仍然按原来的选项显示。

这个设置只在下次打开窗口时起作用，不会改变正在显示的网页。

## 后退、前进、刷新和停止

| 操作 | 工具栏 | 菜单栏 | 快捷键 |
|---|---|---|---|
| 后退 | 地址栏左边的「后退」按钮 | 「历史记录 › 返回」 | ⌘[ |
| 前进 | 地址栏左边的「前进」按钮 | 「历史记录 › 前进」 | ⌘] |
| 刷新 | 地址栏右端的「刷新」图标 | 「显示 › 重新载入页面」 | ⌘R |
| 停止 | 网页加载时，「刷新」图标会变成「停止」 | 「显示 › 停止」 | ⌘.（Command + 句点） |

后退和前进只在窗口这一次打开期间有效。关闭窗口后再打开，之前的前后记录就没了。想找回更早看过的网页，用历史记录。

## 放大和缩小

| 操作 | 菜单栏 | 快捷键 |
|---|---|---|
| 放大 | 「显示 › 放大」 | ⌘+ |
| 缩小 | 「显示 › 缩小」 | ⌘- |
| 恢复原始大小 | 「显示 › 实际大小」 | ⌘0 |

每按一次放大或缩小 10%，最小 25%，最大 500%。缩放比例对所有网页都有效，关闭窗口、退出 Mochi 之后再打开也会保留。

## 网页打不开时

网页加载失败时，窗口里会显示「无法打开网页」，下面写着网址和失败的原因，比如没有联网、网址不存在。

- 检查网络后，点「重试」重新加载。
- 网址输错了，就在地址栏里改正后重新打开。

加载到一半时你在地址栏里打开了别的网址，原来那次加载会被取消，这种情况不会显示这个页面。
