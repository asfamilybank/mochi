# 下载文件

在网页上点下载链接，或者打开一个网页显示不了的文件（比如压缩包、安装包），Mochi 会把它存下来。默认存到你的「下载」文件夹，也可以改成每次询问，或者存到你指定的文件夹。

## 下载的文件存到哪里

默认存到「下载」文件夹，也就是访达侧边栏里的「下载」。

- Mochi 没有下载列表，也不显示下载进度，文件下载完就直接出现在文件夹里。
- 文件夹里已经有同名文件时，不会覆盖它，新文件会自动改名，比如 `报告 (1).pdf`。

## 修改下载位置

1. 按 ⌘,（Command + 逗号）打开设置，切到「通用」面板。
2. 在「下载」一栏，点「文件下载位置」的弹出菜单，选一项：
   - **下载**（默认）：存到「下载」文件夹。
   - **每次询问**：每次下载时在窗口上弹出存储窗口，让你选位置和文件名。选的位置已经有同名文件、你又选了替换时，旧文件会被移到废纸篓，不会直接删掉。
   - **其他…**：弹出选择窗口，选一个文件夹，点「选择」。以后都存到这个文件夹，它的名字会出现在菜单里「其他…」的上面。想换一个文件夹，再选一次「其他…」。

改了马上生效，从下一次下载起按新位置存。

你选的文件夹后来被删除或者改成不能写入时，下载会改存到「下载」文件夹，不会悄悄失败。

## 第一次存到「下载」文件夹时

下载位置是「下载」时，第一次往这个文件夹里存文件，系统会问你是否允许 Mochi 访问「下载」文件夹。选允许，文件就会存下来，以后不会再问。

选「每次询问」或者你自己选的文件夹时，不需要这项权限。

## 提示「无法存到下载文件夹」时

如果之前在系统的提示里选了不允许，Mochi 往「下载」文件夹里存文件就会失败，窗口上会弹出「无法存到下载文件夹」，告诉你 Mochi 没有访问「下载」文件夹的权限，这个文件没能存下来。下面有三个按钮：

- **存到其他位置…**：弹出存储窗口，换个地方存这一个文件。只想先把这个文件拿到手，选这个。
- **打开系统设置**：打开系统设置，让你给 Mochi 授权。
- **取消**：这次不存了。

同时，「设置 › 通用 › 下载」里会显示「上次没能存到「下载」文件夹：需要在系统设置里允许 Mochi 访问」，旁边有「打开系统设置」按钮。之后成功往「下载」文件夹存进一个文件，这条提示就会消失。

想让 Mochi 以后能直接存进「下载」文件夹：

1. 点「打开系统设置」，或者自己打开「系统设置 › 隐私与安全性 › 文件和文件夹」。
2. 在列表里找到 Mochi，打开它下面跟「下载」文件夹对应的开关。
3. 退出并重新打开 Mochi：选择菜单栏的「Mochi › 退出 Mochi」，再打开一次。拒绝过一次之后，**必须重新打开 Mochi 才会生效**，只关掉窗口不算。

不想给这项权限的话，把「文件下载位置」改成「每次询问」，或者用「其他…」选一个别的文件夹，就不再需要它。

## 幽灵模式下的下载

在幽灵模式下，Mochi 不会为下载弹出任何东西，也不会退出幽灵模式：

- 下载位置是「每次询问」时，不弹出存储窗口，直接存到「下载」文件夹。
- 下载位置是「下载」或你选的文件夹时，照常存。
- 存不进「下载」文件夹时，不弹出「无法存到下载文件夹」，这次下载就不成功。下载位置是「下载」时，「设置 › 通用 › 下载」里会显示上面那条提示。

三种模式的完整对照，见[三种模式对照](../reference/modes.md#网页发起的请求)。
