# 清除浏览数据和网站数据

想清理痕迹、退出某个网站的登录，或者某个网站一直不正常时，可以按时间范围清除浏览数据，也可以按网站删除网站数据。

先弄清两个词：

- **网站数据**：网站存在 Mochi 里的 Cookie、缓存等内容，登录状态就在里面。
- **浏览数据**：「清除浏览数据」对话框里能清的全部东西，包括历史记录、网站数据和网页权限例外，网站数据只是其中一类。

## 按时间范围清除浏览数据

1. 选择菜单栏的「历史记录 › 清除浏览数据…」，或者在「设置 › 隐私与安全性 › 网站数据」里点「清除浏览数据…」。两处打开的是同一个对话框。
2. 在「时间范围」里选「过去 1 小时」「过去 24 小时」「过去 7 天」「过去 4 周」或「时间不限」。默认是「时间不限」。时间从你点「清除」的那一刻往前算。
3. 勾选要清除的数据，见下表。
4. 点「清除」。什么都没勾时，「清除」是灰的。

<!-- 📷 images/clear-browsing-data.png — 清除浏览数据对话框（窗口 ID 截图；截图时只打开、不点「清除」） -->

四类数据各清掉什么：

| 数据 | 对话框里的说明 | 清掉的是什么 | 会不会退出登录 | 默认勾选 |
|---|---|---|---|---|
| 历史记录 | 这段时间内访问过的网页，不会退出登录。 | 这段时间内的访问记录，地址栏建议也会跟着变 | 不会 | 是 |
| Cookie 和网站数据 | 会让你退出这段时间内登录过的网站。 | 网站存的 Cookie、本地存储、数据库等，缓存除外 | **会** | 是 |
| 缓存的图片和文件 | 不会退出登录；网站下次打开时可能稍慢。 | 网站缓存在本机的网页文件和图片 | 不会 | 是 |
| 网页权限例外 | 这段时间内新建或改过的摄像头、麦克风网站例外。 | 「设置 › 网站 › 摄像头」「设置 › 网站 › 麦克风」里这段时间内新建或改过的网站例外，这些网站回到「访问其他网站时」的默认值 | 不会 | 否 |

几点说明：

- **只想清历史记录、不想退出登录**：取消勾选「Cookie 和网站数据」，或者直接用历史记录窗口里的「清除历史记录…」，它只清历史记录，见[查找和管理历史记录](history.md#按时间范围清除历史记录)。
- **网页权限例外默认不勾**：这些是你在网页询问框里选过的「访问此网站时允许」「不允许」，或者在设置里改过的网站例外，不想丢的话保持不勾。清掉之后，已经在用摄像头或麦克风的页面不会立刻中断，重新载入页面之后才按新的设置处理。
- **当前页面不会自动刷新**：清掉 Cookie 之后，正开着的网页看上去可能还是登录状态。按 ⌘R（Command + R）重新载入页面，就能看到清除后的样子。

## 按网站删除网站数据

某个网站一直不正常，或者只想退出某一个网站的登录时，单独删掉这个网站的数据就行，不用全部清除。

1. 打开「设置 › 隐私与安全性 › 网站数据」，点「管理网站和数据…」。
2. 列表里每一行是一个网站，下面写着它存了哪些数据（Cookie、本地存储、数据库、缓存、Service Worker、其他数据），以及这个网站的网页权限例外，比如「meet.google.com：摄像头 允许」。
3. 在「搜索」里输入网站的名字找到它，可以按住 ⌘ 选中多个。
4. 按需要点按钮：
   - 「删除数据」：删掉选中网站的全部网站数据，会让你退出这些网站的登录。网页权限例外保留。
   - 「重置权限」：删掉选中网站的网页权限例外，回到「访问其他网站时」的默认值。网站数据保留。
   - 「全部删除…」：删掉所有网站的网站数据，确认后会退出所有网站的登录。网页权限例外保留。
5. 点「完成」关掉窗口。

和清除浏览数据一样，当前页面不会自动刷新，重新载入页面后才会生效。

### 「只有缓存的网站」是什么

很多网站只在你的 Mac 上留下了缓存，没有登录状态，也没有网页权限例外，它们多半是网页顺带加载的图片服务器、广告服务器之类。这些网站默认不在列表里显示，免得挤掉你真正登录过的网站。勾选列表下方的「显示只有缓存的网站」就能看到它们，括号里是它们的个数。在「搜索」里输入文字时，会连它们一起找。

### 为什么删除一个子域名，会连整个域名一起删

网站数据是按整个域名存放的：`meet.google.com`、`mail.google.com` 存下的数据，都算在 `google.com` 名下，所以列表里只有一行 `google.com`。删除时也只能整个域名一起删：删掉 `google.com` 的数据，会让你退出所有 `google.com` 下的网站，而不只是 Google Meet。

网页权限例外不一样，它按每个网址的主机名分别记下：`meet.google.com` 和 `calendar.google.com` 是两个不同的网站。所以在 `google.com` 那一行下面，会分别列出各个主机名的例外。

## 什么不会被清掉

不管是清除浏览数据，还是删除网站数据，下面这些都不会动：

- **书签**：书签只有你自己能删，书签的网站图标也会保留。见[使用书签](bookmarks.md)。
- **设置**：热键、映射、脚本、窗口位置等设置都不受影响。唯一的例外是勾选了「网页权限例外」时，会清掉那段时间内的摄像头、麦克风网站例外。
- **系统权限**：「系统设置 › 隐私与安全性」里给 Mochi 的辅助功能、摄像头、麦克风等权限由系统保管，Mochi 改不了。要清除它们，见[卸载 Mochi](uninstall.md#第三步清除系统权限可选)。

这些数据存在电脑上的哪里，直接删文件会怎样，见 [Mochi 存放的数据与系统权限](../reference/data-and-permissions.md#数据存在哪里)。
